BEFORE YOU STEP INSIDE

A few things
to know.

Is the sample city using my data?

No. This website uses synthetic sample sessions. It never reads your local agent records. Your own city is generated by the installed desktop app using supported local records.

Which agents and computers are supported?

The 1.0.0-beta.3 desktop beta has installers for Apple Silicon Mac (macOS 11 or later), Windows x64, and Linux x64 (.deb and AppImage). Intel Mac packages are coming later. Hands-on testing has focused on Apple Silicon Mac; interactive gameplay on Windows and Linux has not been manually accepted yet. Sources include Claude Code, Codex, DeepSeek Harness, and WorkBuddy. Available statistics, traces, and cost evidence vary by source and version. Check the release notes for details.

What does a building represent?

Data buildings represent loaded sessions. Their height reflects token volume, and sources form districts. Decorative buildings provide scenery. Building growth is a visual metaphor and does not measure task completion or output quality.

Will I see my complete history?

The current City view loads up to 4,000 recent sessions within the selected time range and reports its coverage. Available history depends on the records your agent tools retain. Missing records are not replaced with invented activity.

What if I have no data yet?

Use a supported agent first so it creates local records. In the desktop app, check source status, permissions, and synchronization. No records, denied access, and read failures require different follow-up steps; the website sample remains available to explore.

Are costs actual charges or savings?

Usage-based amounts can be estimates, not charges. Subscription fees and evidenced spend are shown with their own basis; currencies are not directly added together. Comparing a subscription with an API-equivalent estimate does not prove money saved. Desktop City shows per-session estimates in building details; the web demo has no cost data.

Do I need an API key or an account?

No API key or cloud account is required for local analysis. The app reads records your supported tools already leave on your computer; your operating system may ask for permission to read those locations.

Where can I download it and inspect the code?

The project code is MIT licensed. The public source repository is Oh-Agent-AI/oh-agent. Download the 1.0.0-beta.3 desktop beta from the download section below or the GitHub release page. The macOS build is signed and notarized; the Windows and Linux builds are not code-signed yet, so your system may show a warning.
