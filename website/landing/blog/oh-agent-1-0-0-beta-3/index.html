Oh Agent 1.0.0-beta.3 is out: a city you can drive, fly, and lift off in

Published 20 November 2026Oh Agent

releasebetaAgent Citydesktop

The current public desktop beta is Oh Agent 1.0.0-beta.3. We published it on 22 October 2026, as a pre-release, from commit fc0900fb. It is the version the website and install docs still point to: your local agent history becomes a city, and in the desktop app you can take the controls.

This is a beta, not a finished product. The rest of this post is what actually shipped in that cut, and what we are not claiming.

Three ways to explore, in the desktop city

The browser demo lets you walk a sample city and replay activity. It uses synthetic sessions, it does not read your computer's logs, and it does not offer flying or driving. Those modes live in the desktop app.

Once you install 1.0.0-beta.3, desktop City has three exploration modes:

Flight. Free-flight practice and ring challenges. You can leave the street grid and look at the districts shaped by your sessions from above.

Driving. A retro open-top car, a chase camera, and headlights after dark. You follow the streets, cross bridges, and see your history at road level.

Jet roadster. The same car with a jet boost. In VTOL mode, hold Space to climb and release to descend. Land to recharge the boost, then keep exploring on the ground.

This cut also merged terrain grading, bridge-landing, and rendering work into the city you drive through. That is why some approaches and decks feel more continuous than they did in earlier builds. It is not a claim that every road is now certified as passable.

Every data building still starts with a session. Supported sources include Claude Code, Codex, DeepSeek Harness, and WorkBuddy; the statistics, traces, and cost evidence you will see vary by source and version.

How to install it

The packages are on the 1.0.0-beta.3 GitHub Release. Install steps and the support matrix are in the install docs. A SHA256SUMS file sits next to the installers; check the hash before you run a download.

  • Apple Silicon Mac (macOS 11 or later): oh-agent-1.0.0-beta.3-arm64.dmg. This build is Developer ID signed, Apple notarized, and stapled. Hands-on testing has focused here.
  • Windows x64: oh-agent-1.0.0-beta.3-windows-x86_64-setup.exe. This build is not Authenticode-signed; Windows may show an unknown-publisher warning.
  • Linux x64: a .deb for Debian and Ubuntu, and a portable .AppImage. Compatibility for the AppImage depends on the distribution's runtime and FUSE support. These Linux packages are not signed yet.
  • Intel Mac: not in this release.

Windows silent installation, product identity, and bundled CLI checks passed in CI. Linux .deb extraction, desktop-entry, and bundled CLI checks passed, and the AppImage was generated. Interactive gameplay on Windows and Linux has not been manually accepted.

The project itself now lives at Oh-Agent-AI/oh-agent, and it is free and open source under the MIT license.

What this beta does not claim

We published 1.0.0-beta.3 with outstanding City checks left in the open. A road-terrain regression check still classifies one test point as blocked, and a ground-surface geometry digest differs from its pinned baseline. City road passability is not fully certified.

Rust workspace and desktop cargo checks passed, as did a focused payload-URL validation test and the release-artifact contract checks. Full CI and long-duration native driving acceptance were not complete at publication. Those results are not a clean full regression.

One more line we want to keep obvious: some visuals on the website are exploration concepts—illustrated routes over a City view, not recorded gameplay from this build.

If something breaks, please open an issue on GitHub.

If you already have an agent history on your machine, start with the install docs, check the hash, and take the city for a drive. If you want a first look without installing, the sample city is in the browser.
