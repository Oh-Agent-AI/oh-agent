# Agent Vitals — Swept Crest identity

Swept Crest is the selected Agent Vitals mark. The woodpecker represents persistent inspection; the chisel beak and separated node represent a precise runtime finding rather than generic activity or signal strength.

## Core assets

- `agent-vitals-mark.svg`: monochrome, transparent, uses `currentColor`
- `agent-vitals-appicon.svg`: production color composition for the macOS app
- `agent-vitals-menubar-template.svg`: monochrome source for macOS template images
- `agent-vitals-appicon.icns`: packaged macOS icon
- `png/`: transparent master mark and rasterized app icons
- `menubar/`: 1× and 2× menu bar template PNGs

## Brand colors

- Deep navy: `#10182B`
- Mint: `#73E0C1`
- Coral alert accent: `#FF6B6F`

## Usage

- Use the color app icon for Finder, Dock, Settings, and installers.
- Use the monochrome template image in the macOS menu bar so the system can adapt it to light, dark, highlighted, and accessibility states.
- Preserve the eye and the two negative-space cuts. They express inspection and keep the silhouette legible at small sizes.
- Do not add Wi-Fi arcs, signal bars, speed lines, feathers, or a branch.

## Recommended showcase styles

1. UI Container — closest to the actual Tauri product environment
2. Frosted Horizon — premium macOS presentation
3. Clinical Studio — makes geometry and spacing easy to audit
4. Swiss Flat — validates that the mark works without effects
