01 · Geometric

Peck Mark

最直接的啄木鸟侧影与诊断节点。辨识最快、缩小最稳，适合作为主 App Icon 的基础骨架。

02 · Dot Matrix

Pixel Peck

由观测数据点构成鸟形，强调“从日志中拼出事实”。数字感强，但 18px 下可能收缩成点团。

数据感 · 实验性下载 SVG
03 · Line System

Audit Contour

重复轮廓代表持续扫描同一个 Agent。审计含义最强，并刻意采用鸟形闭合路径，避免像无线信号。

审计感 · 轻量下载 SVG
04 · Dots + Form

Punched Inspector

实体轮廓中的三个采样孔对应证据、成本与异常。比 01 更有产品含义，但大孔在小尺寸下会更抢眼。

覆盖率 · 强对比下载 SVG
05 · Monogram

AV Beak

把 A、V 与鸟喙合成一个角形字标。品牌独占性最高，也最像开发者工具，但啄木鸟语义更隐晦。

字标 · 可拥有性下载 SVG
06 · Node System

Runtime Nodes

头、冠与身体由 Agent 节点连接，突出运行时拓扑。产品语义完整，但更适合大尺寸客户端图标。

没有扇形波纹、柱状信号或速度刻度。所有线条都服务于鸟的侧面轮廓与“检查节点”。
