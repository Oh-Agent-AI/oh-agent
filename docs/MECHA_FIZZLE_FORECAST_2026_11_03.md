# PvE 行动落空预告与窄屏回顾（2026-11-03）

## 本轮范围

让玩家在提交前发现当前整队计划中可能失效的行动，并在实际结算后看见落空结果。落空只读取规则模拟产生的 `TurnEvent.act.fizzled` 和原因，不由 UI 从坐标、技能或血量自行推测。本轮不修改回合规则、远程协议或授权边界。

- 当前草稿有落空时，队伍规划区和对应机甲卡片显示警示；展开卡片可查看规则返回的原因和不消耗冷却。结束回合按钮通过 `aria-describedby` 关联警示。
- 目标试算单独提示该候选方案中其他机甲的预计落空与原因，不将既有落空或整队联合作用错误归因于当前行动；候选试算不覆盖当前草稿。
- 上一回合摘要优先展示实际落空，即使同回合取得胜利；胜负继续由目标区显示，完整事件和按实际顺序的生命值变化在展开详情中。
- 无可用预测、远程模式、演出过程或对局结束时不沿用旧的草稿预告。
- 窄屏目标面板依据顶栏实测高度定位，顶栏增加“跳过演出”并换行时不再遮挡按钮；测量回顾位置之前先更新顶栏避让。较高手机屏幕的回顾面板允许较长英文落空原因完整显示；短屏仍使用可滚动面板。手机机甲卡片的状态和风险分行，避免英文单词被挤碎。
