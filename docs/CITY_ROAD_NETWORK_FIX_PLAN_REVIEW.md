日期：2026-10-20。审查对象：`city-visual-style-analysis-a9ddd6` worktree 中的 `CITY_ROAD_NETWORK_FIX_PLAN.md`，其证据基准为 `b1cb7d3d`，不是本工作区未提交修复后的结论。

## 结论

认可“高架落地后用连接器接网”“湾岸借用平行干道”的方向。实施需要补齐以下约束；本文不代表已实现规划修复，也不把计划中的测量数视为已重新验证。

| 事项 | 必须补齐的实现与验收 |
| --- | --- |
| 高架保留率 | 旧版本数量只作回归参考，先区分合法可恢复段与水域/用地/坡度不合法段。保留率不能优先于几何合法性与真实驾驶连通。文中“都不删段”与 C 失败后删除需统一为“有界尝试后允许明确诊断失败”。 |
| 曲线候选 | 候选与最终提交都按完整路幅、用地净空、水域及坡度检查；中心线逐点检查不足以保证宽路可行。曲线采样步长需有上限，避免漏过狭窄禁区。 |
| 落地接驳 | `ConnectionPurpose` 当前仅支持 district-access/site-access/coastal-link，新增 purpose 须贯通策略、诊断与测试。新增道路必须经过同一 admission/transaction，保留路线引用，并参与展示裁剪及驾驶面编译。不能仅保留渲染高架。 |
| 延后接驳 | 若推迟到街网缝合之后，需要明确 pending landing 的生命周期、失败回滚和确定性排序；不要留下开放但未连接的桥端。 |
| 湾岸借道 | 保存岸路、借用干道、连接段的有序关联；后续拆边、环岛改写、solve/remap 均须更新引用。验收连续的宽路子图，不能借助任意支路绕行后称为湾岸连续。 |
| 用地绕弧 | 陆侧应按实际水域场验证，不用固定轴向符号猜测；整段路幅检查水、坡度、其他用地、交叉锐角。失败输出分类诊断。 |
| 搜索预算 | 各曲线变体、A*、挪点重试设置确定性候选数/节点数上限；区分证实不可行与搜索耗尽。 |
| 重映射 | 搜索扩大仍保持合法地块、稳定 tie-break 与去重；建议测量结果后设合理余量，不能为了达到 85% 接受非法摆放。 |
| 基线 | 规划语义确实改变才递增生成器版本，先跑不变量再人工审阅差异；禁止自动刷新 golden 掩盖错误。42/102 不能标全套通过。 |

## 与当前 P1 的关系

- `7/2` 桥端轴向延续撞人行道：已定位为试跑路由假设问题，桥后真实道路需要转向，不能通过扩大路面/碰撞容差修复。
- `1000/7` 桥端：道路与桥板中心高程相合，但端部重叠区域坡面不合，属于结构路面编译问题；规划出口数量恢复并不能自动修复它。
- 正式开放图与出生点：仍需与运行时共用的版本化 fence 几何、最终边界重放及相应证据，路网规划守卫通过不等于正式驾驶发布证据。

建议独立提交顺序：连接器 purpose/诊断契约 → 高架 A/B/C → 湾岸借道及引用 → 用地/短缺口补连 → remap → 既有净距。每步先运行专项，再在最终生成器版本上执行完整套件并记录最终结果。
