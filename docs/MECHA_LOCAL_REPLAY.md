# 本机战斗回放

## 范围

当前实现是 **本地 PvE 的事件重建回放**，不是视频录制。完成一局后，结算弹窗提供“重播、再开一局、退出战斗”三个操作；符合条件的本地对局默认自动保存，也可在战场设置中手动保存。桌面内嵌 City 通过受授权的宿主接口保存在本机 SQLite 数据库；独立浏览器预览保存在该来源的 IndexedDB。两者隔离，不会自动同步。回放保存需要 Web Crypto；每条记录独立，最多 20 条，容量检查与写入在数据库事务中完成，满时不覆盖旧记录。写入后须读回校验才报告成功。

旧版浏览器 localStorage 记录会尝试迁移：原始记录须可解析，数据库写入并读回一致后才移除原记录；迁移失败、冲突或损坏的原记录保留在原处。迁移仅能访问当前来源实际可读的旧数据，桌面隐私 WebView 中已经不可访问的数据不能恢复；失败时在界面提示。

刷新后，在同一应用的数据存储中进入相同的城市，可在“战场设置”选择记录、播放或确认删除。系统会在当前城市的可用战场中自动匹配存档；如果匹配的是另一处战场，回放时临时切换画面，结束后返回原战场，不会重开当前对局。列表时间和回合数仅供索引，播放前仍会重建并验证完整对局。存档依赖兼容的战场与规则版本；如果场景、规则或重建结果不一致，将拒绝回放而不是展示不可靠的内容。清理站点数据可能删除存档，不同浏览器、Web 开发服务与桌面应用不保证共享存储。

播放时可暂停或继续，选择指定回合，也可使用上一回合、下一回合和重播本回合按钮；演出速度可选 0.5×、1× 或 2×，仅影响回放显示，不改变战斗规则或结果。切换或重播会从该回合开头重建演出，并保持当前的暂停状态；历史回放结束后返回原来的战场。 点击“本回合记录”可展开所选回合的完整结算摘要和事件明细；记录可能包含演出尚未播放到的事件，不代表画面已经播放完毕。

保存的是规则参数、部署和玩家行动计划以及校验摘要；读取时由本地规则重算事件和演出，不保存完整城市数据或原始建筑 ID。历史回放不应修改当前局面、草稿或部署。此功能不自动上传，也不涉及远程协议。

## 手动备份与导入

在“战场设置 → 本机战斗回放 → 备份或导入回放”中，可主动把选中的本机记录导出为 JSON 回放文件，也可手动选择文件导入。导出不上传内容；文件不是视频，包含规则参数、部署、玩家行动计划以及校验摘要，应由玩家自行决定是否分享。下载触发后能否实际落盘取决于当前浏览器或宿主的下载能力，需检查下载记录。

导入文件不超过 40,000 字节，仅接受当前支持的严格格式。写入前会在当前城市的可用战场中匹配摘要，按本地规则重建完整对局并校验结果；不匹配、损坏、未结束或战局在校验中变化时不会写入。完全相同的记录已存在时不会重复导入；容量不足或存储不可用会提示且不会覆盖其他记录。导入后通过列表播放，仍不改变当前对局。文件只能在战场和规则兼容时恢复，手动传送不等于跨设备同步，也不保证在不同城市可用。浏览器下载与文件选择已做合成 City 验证，桌面 Tauri 宿主的文件对话框和下载仍需独立验收。

## 本机自动保存

在“战场设置 → 本机战斗回放”中可启用或关闭自动保存；默认开启；用户可在设置中关闭。设置本身保存在当前浏览器或应用的本地存储中。启用后，已结束、存在可回放回合的本地 PvE 对局会尝试保存一次；不会保存远程对局，也不会上传。一次保存失败会显示原因，仍可手动重试；已验证保存的本局不会再次自动保存。满 20 条时不会覆盖旧记录，须先删除记录。

关闭时会取消本页面尚未写入的自动保存；其他标签页更改设置时也会同步，并在写入前再次读取设置。跨标签页检查与写入不是跨进程事务，不应将它视为严格同步保证。存储不可用时，当前页面会关闭自动保存并提示；由于设置可能无法持久化，重新打开后需要检查。关闭自动保存不删除已保存记录。

## 未保存回放保护

已结束且有回合记录的本地对局，如果尚未保存（包括自动保存失败），使用结算页或战斗菜单退出、新开一局，或在战场设置切换战场、脚本时，会先提示回放将丢失；取消后保留当前局。保存中的操作暂不能退出或重开。重开或退出前会重新读取数据库确认已保存记录未被删除或改写；删除、改写或无法访问存储后会重新提示。刷新或关闭网页时只能同步检查最近一次的数据库快照，无法即时发现其他进程或标签页刚删除、改写的记录。原生离开提示是否显示取决于浏览器和用户交互；这不是自动保存，也不能防止进程崩溃、外部卸载或存储清理导致丢失。

## 保存接口与验收边界

市政厅目前还没有回放入口；以后要读取这些记录，需要为市政厅增加明确授权的宿主接口和对应的范围校验，不能直接读取 SQLite 文件或绕过插件权限。现有 City 插件只通过已声明的 `mecha-replays:v1` 固定操作访问本地回放，不接收任意 SQL。

- 使用合成对局记录测试 SQLite 处理器：权限、记录校验、幂等写入、容量限制和读回；额外用独立 SQLite 连接并发争抢最后一个位置以及同 ID 冲突写入，验证不会覆盖既有记录。这不是跨进程或真实桌面 WebView 端到端测试。
- `scripts/verify-city-mecha-native-replay-adapter.mjs` 使用合成宿主验证前端原生 RPC 请求、读回和失败处理；它不运行 Tauri，也不连接 SQLite。
- 浏览器验证使用合成 City 和独立浏览器上下文，不能证明桌面生产 `.app` 中的自动保存、重播或文件对话框正常；桌面原生端到端和人工视觉验收仍待完成。

## 尚未覆盖

- 不是视频文件：没有视频导出、逐帧或任意时间点拖动；回放 JSON 可由玩家自行备份或分享，但需要匹配战场和规则。
- 已提交的回合会暂存在内存中；对局结束后默认自动尝试持久化，也可手动保存。支持手动导入/导出回放文件，但没有跨设备同步。
- 不支持远程 PvE 与 PvP 的录制或回放。
- 浏览器本地验证不代表桌面 Tauri 环境、真实远程对局或未来规则版本已经验收。
