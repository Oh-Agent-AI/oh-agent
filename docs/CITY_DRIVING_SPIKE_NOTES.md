# Coral Coast 合成试驾原型

日期：2026-10-15；分支 `codex/city-driving-car-model`。
对应 [驾驶 SPEC](CITY_GAME_VEHICLE_MODE_SPEC.md) 的 V1 技术验证。此交付可在合成测试场驾驶，**不代表 V1 全部门槛已通过，也不是城市驾驶 MVP**。

## 运行

启动 `npm --prefix apps/agent-city/ui run dev -- --port 5179`，按终端实际端口打开 `/driving.html`。模型页 `/car-model.html` 也有“开始试驾”链接。两个页面都是开发入口，默认 Vite 生产构建不包含它们。

点击“开始试驾”使画布获得焦点；W 加速，S 刹车后倒车，A/D 转向，R 回出生点，Esc 暂停/继续。点击其他控件、切窗口、页面隐藏都会清键并暂停；恢复需再次聚焦画布。失焦不会自动继续，也不补跑后台时间。手机仅可查看，不提供触屏驾驶。

场景为本地合成平面场地、两处矩形障碍与装饰棕榈树；所有几何均项目内生成。没有用户数据、host bridge、存档、外部资产或上传请求。速度显示游戏单位。

## 模块

| 模块 | 本次实现 |
| --- | --- |
| `carDimensions.ts` | 共享车辆尺寸；模型与驾驶查询使用同一轴距/轮距，碰撞范围额外覆盖转向轮包络 |
| `DrivingSimulation.ts` | 1/60 固定步 bicycle 模型、速度相关转向限幅、转向平滑、制动/倒车切换、滚动距离 |
| `DrivingWorld.ts` | 冻结矩形平面 patch/坡面快照、四轮与车体角点支撑、显式同层连接、连续扫掠 SAT 静态矩形碰撞 |
| `DrivingInput.ts` | 仅画布聚焦时 WASD/R/Esc、组合输入/快捷键忽略、失焦/隐藏清键与监听释放 |
| `dev/drivingPreview.ts` | 单帧循环、每帧最多 5 个模拟步、长帧暂停、跟车相机/障碍射线、低频读数、复位及资源清理 |

当前正撞和擦碰均保守停住；碰撞不执行随机弹开，不允许中心穿过薄墙。世界查询会保守拒绝完整车体或轮迹无支撑的位置，边界外不提供自由越野。原型采用小场景线性查询，尚无全城空间索引。

## 验证证据

已执行：

- `node scripts/verify-city-car-model.mjs`：2,016 三角形、11 个主通道 draw；尺寸、灯光、轮动画与释放契约。
- `node scripts/verify-city-driving.mjs`：30/60/120Hz 固定模拟终态误差 <1e-9、先刹停后倒车、相反按键合并、薄墙扫掠、完整车体前缘碰撞、倒车脱离、上层障碍隔离、坡面姿态、窄面/断路拒绝、快照隔离，以及 18,000 步（五分钟模拟时间）的有限状态验证。模拟时间测试不等于真实交互 UAT。
- `node scripts/verify-city-driving-browser.mjs http://127.0.0.1:5179`：Chromium 实际按键前进/转向/倒车、复位、按钮/Esc 暂停、失焦清键、控件焦点隔离、390px 布局和无 pageerror。
- UI `typecheck`、`build` 和 `git diff --check`。

未对现有飞行会话或宿主运行时做修改；本轮不要求启动原生 menubar 裸进程。

## 城市接入前仍须完成

1. 从普通路面、桥梁和高架渲染抽取同源 surface，高程与视觉误差校验；当前矩形平面不是 CityLayout 转换器。
2. 多边形路口/轮迹、跨层显式坡道连接、真实建筑有向占地与空间索引；当前仅支持同层矩形 patch，不能证明桥梁可通行。
3. 轻擦切线滑动、保守边界旋转扫掠的进一步验证、最近安全道路点与无出生点降级；目前 R 回固定合成出生点。
4. 完成 SPEC 中 15 个城市夹具、结构专项测试、CPU P95 和原生 bundle UAT。
5. 驾驶会话接入 City 相机所有权/暂停/退出及投影冻结，隐藏并恢复环境车，再开放正式入口。

以上限制明确保留；不得把本原型改名为“已支持全城驾驶”。
