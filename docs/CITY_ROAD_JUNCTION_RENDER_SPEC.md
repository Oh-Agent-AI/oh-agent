# 路口渲染：路缘圆角 · 主次路等级 · 换宽渐变

> 2026-10-13 · city-opt（生成器 / 渲染）线 · **只改渲染层**：`RoadEdge` / `RoadNode` 数据模型、规划路网、编辑器文件零改动。
> 实现：`apps/agent-city/ui/src/engine/cityRoadJunctions.ts`（纯几何）→ 消费方 `cityTextures.ts`（地面贴图路漆）与
> `systems/roadSystem.ts`（路缘实体）。守卫：`scripts/verify-react-city-road-paint.mjs` 末尾四段。

## 1. 问题

改造前路口就是「两条矩形带子叠在一起」：

- 路面：每条 run 平头描边，≥3 路的节点再盖一个半径 = 最宽半宽的圆盘；转角是直角，颜色取「任一臂是主干就用主干色」。
- 路缘（`buildInfrastructure`）：每条边两端**一律**退 5.5，且整段 < 14 就不画。宽路口 5.5 不够，支路的路缘直接插进主路路面；
  直行一侧又断出 11 的口子。生成器约三分之一的地面边短于 14（3–14 长的度 2 切分），这些边上完全没有路缘。
- 标线：所有路口臂一样——中线虚线退 6、斑马线在 6.5，没有主次。
- 换宽（度 2，12→8→5）：只有一个窄路宽的圆盘补缝，宽度是台阶。

## 2. 设计

一份几何（`roadJunctionPlan`），两个消费方（贴图、路缘）——路面圆角与路缘圆弧按构造一致，不会出现「路面圆了、路缘还直插」。

### 2.1 路缘圆角

- 度 ≥ 2 的节点，入边按方向角排序，逆时针相邻的每一对之间做一个圆角：圆同时切两臂的路面边线（中线外偏半宽）。
- 半径 `r = 1.1 × max(两臂宽)` → 支路 5 → **5.5**，次干 8 → **8.8**，主干 12 → **13.2**（真实路缘半径 5–6 / 8–10 / 12–15 m）。
- **40% 约束**：切点到节点的距离对 `r` 是仿射的（`t = t0 + t1·r`），直接反解允许的最大半径；`r < 0.5` 不做。
  「边长」取**直路链**长度：从路口沿该臂穿过度 2、同宽、非桥/滨水、转角 < 12° 的续接边一直走（上限 80）。
  按单条边算的话，生成器的 10–15 长短边会把所有圆角压没（真机十字口：最短臂 10，圆角全部消失）。
- 夹角 ≥ 177°（直行）不做；切点落在节点背后（不等宽近直行）不做——窄路边线整段藏在宽路路面里，硬画会把路缘画进宽路中央。
- 贴图：人行道先铺「节点 + 半径 r−1.2 的同心弧」，路面圆角（节点 + 弧）在路段之前铺，颜色取两臂中较窄那条（转弯车道属于窄路）。
- 路缘：直段在有圆角的一侧退到切点；超过第一条短边的退让沿直路链顺延到后续边。圆弧用 ≤ 12° 一段的短盒拼（每段多 0.12 咬合）。

### 2.2 主次路等级

- ≥ 3 条地面臂且宽度不全相等 → 等级路口。宽度 = 最大宽的臂是主路，其余是次路；等宽 = 普通路口（不画停止线）。
- **主路直穿**：路段按宽度升序绘制，宽路最后画，铺装盖住窄路伸进来的那截——收口是绘制顺序的结果，不逐口裁剪；主路中线虚线内缩 0（直穿路口）。
- **次路收口**：停止/让行线中心距节点 `s = (主路半宽 + 次路半宽·|cos θ|) / |sin θ| + 0.35`（取最近一条不与次路近平行的主臂；
  次路整幅清出主路——最初只按中线算，斜交口的一角会落进主路，见 `CITY_ROAD_SURFACE_RENDER_SPEC.md`），
  只横跨驶入半幅（右侧通行：驶入方向 −dir 的右手 = `(dir.z, −dir.x)`），宽 0.5；斑马线退到 `s + 1.6`，虚线退到 `s + 2.6`。
  `s` 超过直路链 40% 的不画（短边上会画到路中段去）。
- 节点挂桥面（`bridge` / `structure: "deck"`）→ 整个节点不画停止线、碰到桥面的转角不做圆角；
  滨水大道（`purpose: "waterfront"`）臂不参与圆角、标线沿用旧的 6 / 6.5，路缘沿用 5.5。

### 2.3 换宽渐变（可选项，已做）

度 2、两臂夹角离 180° 不超过 25°、宽度不同：窄臂一侧铺一个梯形，节点处宽路半宽线性收到窄路半宽，长 `min(2 × 宽度差, 40% 链长)`
（12→5 = 14，8→5 = 6）。人行道梯形外扩 1.2；两侧各一段斜路缘接宽路路缘与窄路路缘。弯得更厉害的换宽交给圆角。

### 2.4 最后一道闸：路缘不落在任何路面上

节点级退让只看本节点各臂。生成器会留下 3–4 长的短边，路口的影响范围越过下一个节点；还有个别「无节点相交」的路
（规划残留）。旧代码靠「< 14 的边不画路缘」把它们整段藏起来。现在所有路缘段（直段 / 圆弧 / 渐变斜段）最后都过
`pavementIndex().outside()`：减去它穿过的别的地面路的路面矩形，以及度 ≥ 2 节点的圆盘（圆角线连接在折点外侧铺出的楔形
路面不在任何矩形里），只保留路面外的部分（< 0.5 的碎段丢弃）。
