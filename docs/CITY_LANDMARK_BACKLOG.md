## 1. 合规与表达边界（与既有文档一致，不再放宽）

- CITY_PLANNING_SPEC §4.4：**致敬型地标一律程序化原创几何，不复刻任何具体建筑，不下载现成模型**。
- CITY_VICE_THEME_SPEC §1.2：不复制 GTA 标识、字体、地图、人物、酒店招牌、载具外观；不使用 WELCOME TO VICE CITY / MIAMI 1986 等文案；产品内用原创名称与「迈阿密海滨」表述。

- 全部程序化几何，零外部资产，不占用 5MB 城市资产预算。

## 3. 地标缺口 Backlog

每项给：原型 → 程序化形状规格 → 选址条件（接 §4.4 条件式选址风格）→ 夜景/动画 → 验收要点。优先级 P0（本迭代）→ P1 → P2。

### L-1 度假酒店板楼·冠顶升级（P0）

- **原型**：后现代迈阿密度假酒店——水平阳台带 + 阶梯退台 + **屋顶白格栅鳍片冠**（参考图 2/6 张的天际线主锚点，是整组图里最有辨识度的轮廓语言）。
- **规格**：落点在 citySeaside.ts 现有 hotel lots 上（地基已在，不新增规划层类型）：楼体保持现状，顶部加 5–9 片等距白色格栅鳍片（BoxGeometry 细长片，高 3–5、厚 0.3，沿楼长轴排列）+ 可选阶梯退台（顶层缩进 15%）。实例化进现有 instancedMesh 批次。
- **选址**：无需新选址；对 seed 撒 60–80% 的酒店加冠，其余保持平顶，避免整排同冠。
- **夜景**：鳍片冠底部一条 accent 色霓虹带，复用现有 nightLights 门控。
- **验收**：seaside 守卫断言「有冠酒店数 ≥ 阈值且 < 总数」；目视截图确认天际线出现鳍片断点。

### L-2 屋顶立牌与路边双柱广告牌（P0）

- **原型**：Vice City 最强的尺度符号——屋顶广告板与路边大招牌（参考图 2 张：顶楼广告板、粉/青霓虹招牌带）。
- **规格**：两种件：① 屋顶立牌（双柱 + 面板，面板 6×3，略前倾 5°）撒在 ≥24m 的商业楼顶；② 路边双柱牌（面板 8×4，高 8–12）沿主干道商业段放。面板底色从主题 palette 取，正面夜间霓虹描边（发光材质，随昼夜门控）。**文案只用原创中性词或纯色块+抽象字距**（"HOTEL" 一类通用词可用；禁用 Vice spec §1.2 点名的文案）。
- **选址**：城市分区 zoning 判定商业楼顶 + 主干道两侧净空检查（复用 SegmentIndex 距离查询，避开路口 20）。
- **验收**：新守卫或并入 decor 守卫：牌面不与楼体/道路相交、数量有上下限、夜间截图可见霓虹描边。

### L-3 地中海复兴庄园（P1）

- **原型**：白灰泥墙 + 红陶四坡顶 + 临水拱券柱廊 + 端头小钟塔（campanile）。6 张里出现 3 张，是滨海焦点锚点——我们 9 种地标里**完全没有**低层纪念性建筑，天际线只有「塔」没有「园」。
- **规格**：新 LandmarkKind `villa-complex`：2–3 层长条主体（60–90 长）+ 沿水一侧连续拱廊（拱券 8–12 跨，券心等距）+ 四坡红陶顶（低饱和赭红）+ 一端方形钟塔（细、顶小穹盖）。全 BoxGeometry/CylinderGeometry 拼装。
- **选址**：海湾内侧静水岸（与 sail-opera 错开方位角），或 park site 相邻；miami/mediterranean 生态权重 4，其余 1（仿 pagoda 的 biome 加权模式）。
- **夜景**：拱廊内暖黄点光带（实例色即可）；钟塔顶部一盏常亮。
- **验收**：planning 守卫断言该地标出现在静水岸/公园邻接位且 clearance 满足；截图纳入城市验收。

### L-4 机场岛（P2，最大件，单开一批）

- **原型**：民用机场区——跑道 + 塔台 + 壳形航站楼 + 登机桥指廊（参考图独占 1 张，是 coastal-resort 城市的标配大件）。
- **规格**：新 publicSite kind `airport` + 岛外填海平台（矩形平台，跑道 200–260 长、白中线/边线/端头斑马线，CityGeometry 全平面绘制）；壳形航站楼 = 扇形褶皱壳（沿弧排列的三角面，Saarinen 语系的通用壳形，不参照具体航站楼）；塔台 = 细混凝土身 + 悬挑玻璃顶舱；2–3 条登机桥指廊（细长方管，微斜）。
- **选址**：主岛外一侧浅水区，与 L-5 堤道配套；平台不得占用航道外既有用海（避开 harbor 方位）。
- **夜景**：跑道边灯（成排小点光，实例色）、塔台顶红灯慢闪。
- **依赖**：L-5 堤道先行；填海平台涉及 terrain height field 扩展，需单独评审（影响 geography 守卫基线）。

### L-5 多跨堤道桥（P1，可独立于机场先行）

- **原型**：低矮长桥 + 等距排架墩序列（Y 形墩/方墩），斜穿水面形成构图对角线（3/6 张，是跨海连接的通用形态）。我们现有桥全是单跨过河/过湾，没有「长堤道」节奏。
- **规格**：新桥型 `causeway`：薄板桥面（高跨比 < 1:12）+ 等距墩（间距 18–24，墩高随地形），复用 infrastructure 已有的 deck/rails/piers 构件，新增「多跨连续 + 微拱纵断面」两个参数。护栏延续现有 edge lines。
- **选址**：主岛 → 近岸离岛（先于机场存在时，连接任意离岸高地）；桥身全程水面占比 > 60% 才配此型。
- **验收**：扩展 verify-react-city-infrastructure.mjs：多跨墩数 ≥ 阈值、纵断面微拱、护栏标线连续。

### L-6 圆筒玻璃塔（P1，以楼型变体落地）

- **原型**：圆柱幕墙塔（3/6 张背景天际线），与板楼形成轮廓对比。
- **规格**：**不新增 LandmarkKind**，作为 downtown 楼型的 cylinder 变体：CylinderGeometry 16–24 边、竖向分格（条纹材质复用 facadeFor）、高度 40–70。downtown 分区按 seed 出现率 10–15%。
- **验收**：layout 守卫断言 cylinder 变体存在率区间；目视确认轮廓多样性。

### L-7 红色穿式桁架桥（P2）

- **原型**：红色格构桁架公路桥（1 张），工业年代感，与悬索桥互补。
- **规格**：桥型第二形态 `truss`：上下弦 + 斜腹杆格构（instanced 细杆），深红涂装；跨 60–90，替换工业港方位的一座过河桥（与 suspension-bridge 的择桥逻辑互斥）。
- **验收**：infrastructure 守卫：桁架杆件数区间、与 suspension-bridge 不同时占用同一座桥位。

### L-8 工业港仓储配套：筒仓与集装箱堆场（P2）

- **原型**：白圆柱穹顶罐成组 + 彩色集装箱矩阵（2 张，与龙门吊同框）。
- **规格**：harbor site 半径内：2–4 座筒仓（CylinderGeometry + 穹顶盖，白/浅灰）+ 集装箱堆（2–3 色小盒矩阵，堆高 1–3，留出吊机作业通道）。避开码头岸线。
- **验收**：decor/守卫断言件数与位置约束；与龙门吊无穿模。

## 4. 构图规则（规划/渲染层，非单体建筑）

参考图反复印证、比单体地标更值钱的三条：

- **C-1 近岸高度梯度**（P1，收益最大）：真实迈阿密剖面是「棕榈堤道 → 低层庄园/绿带 → 后排公寓墙」——**塔楼被推离水岸**。落点：cityPlan 的 waterfront/高度函数加「离岸 < hotelOffset+40 内限高 ≤ 4 层」约束，塔楼只出现在其外。验收：planning 守卫断言近岸带 max height 上限。
- **C-2 轮廓标点**（P1）：天际线节奏靠屋顶配件打断板楼单调——天线、水塔、helipad 圆圈、格栅冠，按 seed 撒在 ≥24m 楼顶（L-1 的冠是其中最装饰性的一种）。验收：守卫断言配件覆盖率区间（如 25–45%）。
- **C-3 三层景深取景**（P2）：前景框景（棕榈/堤道）→ 中景低层带 → 远景塔群。落点：cinematic 镜头种子与首屏默认机位；验收并入 cinematic 守卫的可选断言。
