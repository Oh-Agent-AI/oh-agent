# 玩家汽车模型首轮交付

日期：2026-10-15。分支：`codex/city-driving-car-model`。
对应 [驾驶 SPEC §12–13](CITY_GAME_VEHICLE_MODE_SPEC.md)。模型阶段已完成；随后新增合成试驾原型和轻量驾驶模拟，尚未接入真实城市路面。

## 实现

- `apps/agent-city/ui/src/game/CarVisuals.ts`：项目自有程序化珊瑚粉双门敞篷跑车（Coral Coast），独立四轮、前轮转向、轮胎滚动、刹车/倒车灯、车身姿态接口、幂等释放。
- +X 向前、+Y 向上、+Z 向右；正 heading 朝 +Z，内部转为 Three.js 的负 Y 旋转。pitch 为局部 Z 轴抬头角，roll 为局部 X 轴侧倾角，均为弧度。
- 根节点在接地平面；包络不超过长 2.8、宽 1.4、高 1.15。模型 2,016 三角形、11 个单材质 mesh；投影阴影需要额外绘制，不包含在 11 次主通道预算内。
- `update()` 接收总行驶距离和姿态，完全不积分模拟、不读键盘、不依赖真实数据。调用方传入有限的插值状态；累计距离按世界单位计算。
- 环境车保持原实现；玩家车不导入生产入口，合成试驾页由独立开发会话创建和释放。

## 本地预览

运行 `npm --prefix apps/agent-city/ui run dev -- --port 5179`，打开终端实际给出的端口下 `/car-model.html`。如端口占用，以 Vite 输出为准。

支持拖动/缩放、四个预设视角、前轮转向、播放/暂停滚轮、倒车、刹车灯和昼夜。默认静止，无自动旋转；减少动态效果偏好切换为开启时停止动画，仍可主动播放。预览是开发入口，不纳入默认生产构建。

## 验证

- `node scripts/verify-city-car-model.mjs`：模型包络/接地、有限顶点、三角形和 draw 预算、heading/转向/倒车滚动方向、灯光状态、重复释放。
- `npm --prefix apps/agent-city/ui run typecheck`、`npm --prefix apps/agent-city/ui run build`。
- Chromium 浏览器冒烟：四视角、转向控件、滚动开关、倒车/制动、昼夜、减少动态效果环境、390px 窗口无横向溢出；无 pageerror。前/侧/后与夜间截图人工复核。

未验证：城市真实灯光中的视觉、坡面四轮支撑、驾驶相机遮挡、原生 WebView。它们随驾驶世界和会话集成完成；本轮只支持合成试驾，不声明真实城市已可驾驶。

## 敞篷造型修订

用户确认 Vice City 气质方向后改为原创复古敞篷：珊瑚粉楔形车身、米白双座与头枕、开放座舱、透明倾斜挡风玻璃、抬起式前灯、后部散热格栅、多辐轮毂。无车顶、无外部资产；保持既有尺寸包络、11 draw calls 和动画接口。
