# 射击不可用原因：实现与验证（2026-11-03）

## 范围与行为

本地 PvE 规划时，如果射击或穿射没有合法目标，玩家可以键盘展开「当前不可用行动」，按存活敌人查看第一个不满足条件以及阻挡格。它依据全队当前草稿移动落点，而不是只看选中机甲的原始位置；修改或撤销移动会刷新。技能冷却单独提示，不伪称无目标。

合法性和解释共用同一套射线判断：距离、同行列、山地、不可穿透障碍、掩体/建筑/废墟以及其他单位。穿射可以忽略一个掩体类占格，射线从射手向目标遍历，报告真正造成阻挡的那个格子。Boss 使用原有规则所选的最近同行列 footprint 格判断射击；列表中目标坐标仍是 Boss 锚点。当前规则中水面和高度不阻挡射击，界面没有将它们描述成阻挡原因。此项没有更改实际射击合法性。
