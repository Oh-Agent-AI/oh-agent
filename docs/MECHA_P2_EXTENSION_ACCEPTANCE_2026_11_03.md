# Mecha P2 扩展能力首版验收记录（2026-11-03）

## 范围与结论

本次在既有 P0/P1 工作基础上接入 P2 的若干本地 PvE 能力与实验；**并非 P2 全部完成或产品验收通过**。保留结算弹窗原有三个操作：重播、再开一局、退出战斗；复盘内容通过只读折叠区显示。没有添加遥测、隐式上传或外部联网。

## 已接入

- **快速指南**：从战斗顶栏菜单主动打开中英文指南，介绍部署、敌方预告、规划、回合提交与回放；Escape 关闭指南并返回焦点。它不会暂停自动或远程对局，也不是自动触发的分步教学。
- **逐回合复盘**：在本地结算展开后按需读取本局记录，对每回合执行规则重演，核对提交计划、结算日志与完整状态；缺失或不一致时显示不可核验，不推断因果。仅展示已核验的事件与统计，不提供自动战术建议。
- **可选战斗事实**：本地 PvE 胜利时展示“全员生还”和“受保护建筑无损”的可核验事实；救援任务没有保护建筑目标时明确标注不适用。缺少完整证据则显示未知。这不是评分或奖励体系，不影响胜负。
- **精选战场组合**：在战场设置中组合当前城市可用场地与现有敌方脚本，并在开始前确认替换当前对局；继续沿用未保存回放保护，远程期间不可用。选择前验证场地、敌人阵容与合法部署，条件不足明确拒绝。当前四个组合不是新地图或新敌人类型，各城市可用情况不同。启动后仍由玩家部署；同一场地重复启动不应卡在模型加载状态。

## 原型和性能结论

- **挑战开局编码仅为内部原型**：`challengeCode.ts` 生成版本化规则开局数据，避免本地世界坐标和原始实体 ID；校验和只用于检错，不提供真实性认证。尚无玩家可用的创建、导入、分享或固定解界面；没有规则代码指纹，未证明所有部署/未来版本的重建一致性，也不能还原城市 3D 场景。不能称为已完成可分享挑战或社区固定局面。
- **AI Worker 暂不迁移**：隔离 Chromium 基准中起伏地形代表性搜索 p95 为 48.70/46.40 ms；合成定时器推迟不能等同真实输入延迟。还需在目标 Tauri/WebKit、真实交互路径和代表性设备上测量，并比较含复制、取消及回退的 Worker 原型，再决定预算或 Worker 化。现有 Worker 是战场选址用途。详细方法和原始结果见 `MECHA_P2_AI_BENCHMARK_2026_11_03.md`。
