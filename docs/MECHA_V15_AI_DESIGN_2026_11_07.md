# 机甲战棋 v1.5 AI 命令策略设计

日期：2026-11-07  
状态：C2 实施设计，待 B、C1 完成后实施  
依据：`MECHA_V14_RETIREMENT_EXECUTION_2026_11_07.md`

## 目标

AI 操作与玩家使用同一个 v1.5 权威：每条移动、行动和结束回合命令立即结算，后续选择基于更新后的棋盘、剩余机会和敌方意图。支持攻坚、守楼两种打法、建议与自动对战。规则、数值、协议和回放格式沿用对局选定的版本。

## 状态与边界

- 输入是当前 `SequentialTurn` 权威的隔离搜索分支，包含 `match`、行动权、待撤销移动、检查点、重置权、状态账本和当前 revision。不得仅从 `MatchState` 重建，否则已用机会和撤销状态丢失。
- `SequentialTurn.trial()` 目前只返回一个命令的结果，无法连续推进多条假设命令。C2 需新增受控搜索分支接口，使多条命令在同一隔离分支顺序执行；分支不得修改真实权威、真实事件接收器、持久化或命令去重状态。不得用 `records()` 全量重放做每个节点的预览。
- 决策返回尚未带持久化 ID 的命令意图及其基础 revision。控制器重新校验当前 revision、自动模式、演出和存储状态，再为真实命令分配 ID 并走 `executeDurable()`。候选、评分和策略信息不写入回放。
- 手动建议和自动对战共用同一个策略。建议仅展示下一步及其解释，由玩家确认；自动对战逐条提交，等待持久化及演出完成后从新状态重算。

## 候选与搜索

1. 从当前分支枚举每台存活、可操作机甲。合法移动通过现有路径、占位、状态限制与 `moveBudget` 产生，并由权威分支执行校验。
2. 对每个移动后的棋盘重新调用 `legalActions` 并绑定目标。也枚举原地行动、待机和合法的结束回合。冻结机甲仍可行动，眩晕机甲不可主动移动或行动；终局立即停止。
3. 搜索以单条命令为边，探索不同机甲的行动顺序。每次模拟命令都使用分支当时的 revision 和唯一模拟 ID。候选必须覆盖推挤、碰撞、死亡、状态和敌方意图的即时变化，不缓存执行前的合法目标。
4. 对候选续着在隔离分支上执行 `end`，用真实敌方阶段和状态结算评估回合末局面。结果应区分已知、不可用和终局；不可用不得当作零伤害或安全。
5. 使用固定宽度 beam search，先按明确的节点上限、深度上限和稳定次序裁剪。节点上限达到时保留已验证的完整候选；没有完整候选时给出不可用，自动模式停止并提示。不要基于机器时间裁剪，以免同局面产生不同结果。具体上限以基准测试确定，并作为策略配置版本固定。
6. 同分时使用稳定顺序：机甲 ID、命令类型、坐标、目标 ID、完整规范化命令序列。不得依赖对象遍历偶然顺序或随机数。

## 评分

- 优先比较终局：胜利优于未结束，未结束优于失败。其次比较受保护建筑损失、机甲生存与伤害、敌方生命损失和击杀、位置及剩余威胁。不同打法调整这些因子的权重。
- 使用模拟起点到结果的实际变化，伤害来自已验证的事件与生命时间线；治疗不能抵消累计受伤，召唤、消失和死亡不能靠 roster 差分猜测。证据不足时该候选不可评分。
- 状态效果、位移和碰撞通过权威模拟自然进入评分。冻结、眩晕、持续伤害及终局要按照对局的状态规则版本结算。若效果规则以后扩展到小怪，策略应消费权威结果而不为怪物写特例。
- 可复用旧评分因子的名称和可解释数据结构，v1.5 权重需独立版本和基准。复用现有基线时不得修改战斗数值。

## 运行安全

- 保存失败、确认不确定、规则拒绝、无合法候选、演出失败或用户停止时，停止自动对战并展示原因。不得后台重试可能已经提交的命令；恢复必须先重新读取并核对检查点。
- 搜索期间和命令执行前均检查状态版本。用户输入、结束回合、重置、退出、切换对局或其他窗口写入使候选过期，丢弃候选并重算。
- 真实命令逐条可回放。自动策略停止后，玩家可以接管；不使用隐式批量提交。部署、远程交接和 PvP 不在 C2 本地自动对战范围内。

## 验收

1. 同一开局、revision 和策略配置多次运行得到相同命令序列、日志和结果；输入对象及持久化内容不因搜索改变。
2. 搜索与真实逐条执行一致，涵盖先移动后攻击、先攻击放弃移动、跨机甲顺序、撤销后重选、击杀后目标失效、推挤、碰撞和建筑损失。
3. 冻结、眩晕、毒火结算、未使用机会确认、敌方阶段、胜负及回合重置均遵循对应状态规则；不支持的遭遇明确不可用。
4. 固定 fixture 比较有无障碍、不同攻击方向、低血机甲、濒危建筑、攻击 Boss 与防守威胁，核对决策理由及终局优先级。探索节点数、内存、耗时和界面响应在桌面与窄屏记录基线。
5. 人工接管、停止、持久化失败、冲突 revision、演出中断、重新加载与回放必须收敛到权威状态；自动对战不能重复提交命令。
6. 增加 v1.5 策略单测、命令序列回归、浏览器完整自动战斗与恢复测试。保留 v1.4 AI 的独立回归直至 D 阶段，运行 `npm run typecheck`、`npm run verify:mecha` 和 C2 浏览器验收。
7. 冲撞与其他强制位移须覆盖小怪和机甲作为受击目标；再次撞上单位或建筑时，以对局规则版本的碰撞结算为准。AI 应模拟受击对象、阻挡对象的伤害及位置变化，并验证两类对象和连续碰撞。先核对并补齐权威规则，不能仅在 AI 评分或表现层伪造位移。

## 阶段依赖

按既定顺序完成 B、C1 后进入 C2。C1 的怪物 catalog 和效果规则决定候选覆盖；小怪副作用仍需单独确定兼容旧记录的版本策略，不能在 AI 模拟里猜测未定义效果。
