## 2. 三种算法的要点与对我们的意义

### 2.1 张量场流线（MapGenerator）
- 用 Grid 基场（方向、衰减）与 Radial 基场（中心）叠加成张量场；海岸、河流也可作为基场。
- 沿主/次特征方向积分出流线：`dsep`（种子最小间距）、`dtest`（积分时与已有路的最小距离），
  主干 / 次干 / 支路三档参数（默认 400/200、100/30、20/15）。**积分时 `dtest` 就挡住了并排路**。
- `joinDanglingStreamlines`：断头沿自身方向在 `dlookahead` 内找最近样本点，**只接前方、夹角 < joinangle（约 30°）**，
  否则不接；连上后把端点往前推 `simplifyTolerance×4`，保证交点在简化后不丢。
- 建图：所有流线段做扫描线求交（isect.bush），交点与端点按半径模糊合并成节点。

**意义**：天然解决「沿岸两条平行路」（同向流线由 dtest 保证间距）；道路顺海岸与河弯。

### 2.2 优先队列增长 + 局部约束（Procedural-Cities，Parish–Müller 系）
- 段按 `time` 进优先队列；每出队一段做 `placementCheck`：与已有段中点太近则拒绝；与已有段相交则 `collideInto`
  （截断到交点，该段不再扩展）。
- `addExtensions`：主干每段可向前 + 左右各出一条（主干 / 次干），次干只出次干；分叉带噪声与密度惩罚。
- 收尾：每个前方无路的段把终点沿切线延伸 `maxAttachDistance`，与最近的段求交，命中则截断接上。

**意义**：增长期就处理连接，不留到事后；与我们 `connectToNetwork` 同源，但约束在生成时执行。

### 2.3 瓦片位掩码（micropolisJS）
- 每格查上/右/下/左四个邻格是否为路，组成 0–15 的掩码，查表得直路 / 弯 / T / 十字。

**意义**：路口类型由**连接拓扑**决定，而不是几何猜测。我们的「路面接缝 / 路口补圆」应按节点度数与
入射路段等级查表出形状，而不是统一画圆盘。

## 3. 我们的路网生成方案

```
network/
  field.ts        张量场：Radial(核心) + Grid(各城区主方向) + 海岸/河流边界场
  trace.ts        流线追踪（主干、沿岸路、次干三档参数），积分时 dtest 防并排
  grow.ts         街网：扇区网格保留（街区与地块依赖它），横街按优先队列增长 + 局部约束
  connect.ts      统一连接器（§4），生成期与修复期共用
  graph.ts        交点建图、节点模糊合并、路段等级
  junctions.ts    路口类型表（§5），供渲染与守卫读取
```

- **骨架**：放射主干沿 Radial+Grid 场追踪替代直线放射；**沿岸路 / 河岸路**沿边界场追踪替代「离水线 22 取点」，
  遇用地、高架改为绕行而非断开成段。
- **高架环线**：仍按半径取点，但积分时与沿岸路保持 dtest（解决西海岸并排）。
- **街网**：保留现有扇区网格（地块、zone、守卫都依赖它），只把横街接入、断头处理换成 `connect.ts`。
- 确定性：场与噪声走 seed + DetMath；不引入任何 `Math.random`（MapGenerator 的 `collideEarly` 用了随机，不照搬）。

## 4. 统一连接器 connect.ts（生成期与修复期同一函数）

对每个新段端点，按顺序：

| 步 | 规则 | 参数 | 来源 |
| --- | --- | --- | --- |
| 1 | **吸附候选**：端点 r 内有节点 → 试算兼容节点合并及重复边消解，通过后并入 | r = 6（支路）/ 10（主干）是调研候选范围；与当前 0.5 近接诊断分开 | MapGenerator 模糊合并 |
| 2 | **截断**：新段与已有段相交 → 切到交点，生成路口，停止扩展 | — | Procedural-Cities collideInto |
| 3 | **前向延伸**：前方 L 内、夹角 < 30° 有路 → 延伸接上 | L = 40（支路）/ 120（主干） | 两者共有 |
| 4 | **垂直接入**：投影落点夹角 ≥ 60° → T 接 | maxDistance 按等级 | 现有 connectToNetwork |
| 5 | **拒绝**：普通地面路过水、穿用地、坡度 > 0.9、与同级路平行间距 < dtest；引道/桥面采用具名结构合同 | dtest：主干 30 / 支路 15 为调研参数，生产值须标定 | MapGenerator dtest |

被拒绝的端点：若离用地边缘 ≤ 12 → 记为门前终点；否则进入修复循环的「断头」约束。

上述距离仅供生成入口候选，不能直接授予合法尽端：须有 owner/实际入口用途与主网路径，
失败的 required 连接继续计为失败。生成、修复和报告共用端点接触/T/内部交叉/共线/近接分类。
不自动吸附跨层节点或桥上投影；桥头接地只在明确的结构与干地合同内接受。

## 5. 需要支持的连接模式（路口类型表）

由节点度数 + 入射路段等级 + 夹角决定（位掩码思路的连续版）：

| 模式 | 判定 | 渲染 / 处理 |
| --- | --- | --- |
| 直通 | 度 2，同级，夹角 > 150° | 连续路面，不画接缝 |
| 弯 | 度 2，同级，夹角 ≤ 150° | 圆角拐弯（按宽度取半径） |
| 等级过渡 | 度 2，不同级 | 渐变楔形过渡段（长度 = 宽差 × 3），不再用圆盘遮缺口 |
| T 路口 | 度 3 | 主路连续，支路接入处退线 + 停车线 |
| 十字 | 度 4 | 四向路口铺装 |
| 近距合并 | 两个 T 相距 < 12 | 提出合并/重定线候选；支路、角度、重复边、owner/车流和完整路幅通过后才改图 |
| 主干环岛 | 度 ≥ 5、≥ 3 条宽 12 主干交汇，或四条宽 ≥ 8 干道交汇 | 半径 18/16/14、环道宽 8；净距/走廊/角度不合格时拒绝，保留原路口 |
| 支路小环 | 三至四条宽 5 支路交汇 | 按种子稀疏抽样，半径 10、环道宽 5，复用事务校验 |
| 锐角接入 | 夹角 < 30° | 不允许；改为先拐直再接（修复规则） |
| 桥头 | 一侧是桥 | 留 14 净空，不允许用地贴近 |
| 立交 | 高架与宽 ≥ 8 地面路交叉且夹角 ≥ 50° | 安全位置生成菱形匝道；沿实际高架并入、落在有限地面宿主上。分流段同高，两端护栏开口；不合格时仍为上下穿 |
| 断头 | 度 1 | 只允许：门前、海岸、公园、码头 |
| 水上连接 | 堤道 / 岛 | 设施落位、岛侧入口、桥、岸侧引道与主网路径原子接受；岛端合法尽端须有明确 owner |

## 6. 修复循环中的路网约束（接入 CITY_ARCHITECTURE §2）

| 约束 | measure | repair |
| --- | --- | --- |
| no-parallel | 同级路平行（< 20°）且间距 < dtest 的段长 | 删除较短一条，端点用 connect.ts 重接 |
| no-acute | 路口相邻夹角 < 30° | 三岔口先建小型交通环（city-roundabout 批次：mini-roundabout 策略档，删是最后手段）；建不成删较短的窄路 |
| merge-close-junctions | 两路口间距 < 12 | 合并节点 |
| no-loose-end | 不允许的断头 | connect.ts 步 3/4；仍失败则删除悬挂链（< 40） |
| grade-transition-at-junction | 等级变化发生在度 2 节点 | 把变化点移到最近的路口 |
| connected | 连通分量 > 1 | 分量间最短可行连接 |

## 7. 验收

新增近接/短腿回归覆盖 0.02/0.16/0.5 缺口、共同邻点的重复边、灰区角度、多岔/折线/共线与
桥域误合并；拒绝后零副作用。完整与展示图中的未接地面关系必须显式入门禁，不以现有路型表
覆盖或截图路面连续替代共享节点。成功产物的 required 主网/入口/桥头关系须全部满足，
旧普查残留上限与新能力目标分开，详见残留闭环 SPEC §7。

- planning 守卫新增 / 收紧：并排宽路段长 = 0、锐角 ≤ 2、断头（不允许类型）= 0、近距路口 = 0。
- 路口类型表覆盖率：每个节点都能归入 §5 一种模式（守卫断言没有「未分类」节点）。
- 真 GPU 俯拍：西海岸并排路消失；路面在等级过渡处连续。
- 跨引擎确定性不变（V8 = JavaScriptCore）。

## 8. 分步

| 步 | 内容 | 估算 |
| --- | --- | --- |
| 1 | `connect.ts` 抽出统一连接器，现有各处接入改调它（行为等价） | 1 天 |
| 2 | 路口类型表 + 守卫（只读，先度量） | 0.5 天 |
| 3 | 修复约束 no-parallel / no-acute / merge-close-junctions / grade-transition | 1.5 天 |
| 4 | 渲染按路口类型画过渡段与弯角（替代圆盘补缝） | 1 天 |
| 5 | 沿岸 / 河岸路改为边界场追踪 | 2 天 |
| 6 | 放射主干改张量场追踪 | 2 天，可选 |

步 1–4 可先于 CITY_ARCHITECTURE 的完整约束框架落地；步 5–6 依赖张量场，收益是形态更自然。
