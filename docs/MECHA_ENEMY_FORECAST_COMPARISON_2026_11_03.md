# PvE 目标试算：敌方行动对照（2026-11-03）

## 目标与范围

在本地 PvE 选目标时，把候选方案与**当前草稿**的两次 `previewPlan` 整回合模拟进行比较；这不是当前敌方宣告与试算的对比，也不把所有变化归因于选中的那次攻击。未修改战斗规则或远程协议。

## 实现

- 按敌人分组对照实际执行的事件，提示不再出手、新增出手、出手变化，以及两次出手数、技能（有变化时）和攻击格。使用事件多重集比较，忽略单个事件里格子的顺序；不比较伤害、全局执行顺序或每次攻击与格子的配对变化以外的状态。
- 面板顶部显示整回合变化摘要，详情注明其他机甲行动和胜负提前结束可能引发连锁变化；因此“不再出手”并不等同于“本次行动打断技能”。
- 候选或草稿预测失败、版本不一致时，比较结果为未知，不得误判为安全或没有变化。
- 点选目标后棋盘蓝色预测使用候选模拟，红色仍是当前宣告；取消后恢复草稿预测，确认后显示新草稿。悬停仅在桌面展示结果，棋盘仍为草稿。候选预测不可用时蓝色预测为未知；选中期间隐藏棋盘上的草稿顺序编号，避免混淆。图例明确标注数据来源。
- 手机和桌面的目标面板保留滚动、键盘和退出操作；结果较长时提供末尾滚动余量，避免滚动边缘裁切文案。

## 边界

- 本轮不比较行动造成的伤害差异、敌方顺序变化、修理后是否能扛住关键攻击，也不证明技能被中断的具体原因。详情显示的格子是某敌人整回合攻击格的并集，非逐事件时序图。
- 规则当前 `telegraphByActor` 使用同一敌人的最后一次事件；比较器支持重复事件，棋盘对同一敌人的聚焦尚未覆盖未来多次出手的全部格子。
- 合成浏览器测试不代替真实设备、原生 Tauri、全部视口和远程 relay 验收。远程 PvE 部署中恢复与 PvP 隐藏部署仍未完成。
