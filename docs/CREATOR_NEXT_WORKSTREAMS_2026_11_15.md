# Creator/City 后续独立工作流（2026-11-15）

状态：**计划，不是已完成能力**。本文把三个长期项从「Creator Studio 发布收口」中拆出，避免用规范文档或局部代码冒充完成。发布验收矩阵见 [CREATOR_STUDIO_ACCEPTANCE_2026_11_14.md](CREATOR_STUDIO_ACCEPTANCE_2026_11_14.md)。

## A. CAS 资产管理与 GC

规格：[CITY_ASSET_MANAGEMENT_SPEC_2026_11_15.md](CITY_ASSET_MANAGEMENT_SPEC_2026_11_15.md)。当前只有提案。

- **目标**：`sha256` 内容寻址唯一字节存储，`creator_assets` / `creator_asset_refs` 账本，跨项目物理共享、逻辑隔离；零引用才可清理，GC 先预览后删除。
- **先决条件**：项目导入、release、内容包安装、Studio 导出四条写路径统一经过 CAS；禁止新增第二套路径。
- **验收门槛**：
  1. 同 digest 多项目/多 release 只存一份字节；删除一个引用不影响其他。
  2. 崩溃孤儿 CAS 文件按摘要收养；账本与字节不一致会被检测。
  3. GC 只清零引用，引用中的资产拒绝删除；有磁盘总量预览。
  4. 迁移期旧 `state/creator/projects/<id>/assets` 可回退读取，切换后可移除。
- **不做**：不改现有 GLB/资产预算上限；不引入网络下载或远程资产。

## B. 官方 Miami 内容迁移

规范：[CITY_PROJECT_DIRECTORY_SPEC_2026_11_14.md](CITY_PROJECT_DIRECTORY_SPEC_2026_11_14.md) §7。当前只有 `apps/agent-city/worlds/miami/` 骨架与基线文档，应用代码未迁移。

- **目标**：官方 Miami 与自定义世界使用同一 world profile/scene/asset 目录与内容包契约；官方应用仍是 trusted runtime，不把应用代码打进数据包。
- **顺序**：
  1. 盘点官方 Miami 当前 profile/seed/生成器版本/内置资源/游戏及用户数据边界。
  2. 用固定合成输入建立 `worlds/miami/world/`，与旧实现逐字段对照。
  3. 统一内容身份/digest 解析，但保留官方插件 typed-data 授权边界。
  4. 在备份/隔离测试数据上验证升级、重启、迁移失败回退与双城隔离。
  5. 只有固定构建、资源完整性、双城隔离、真实用户升级验证全过，才切换构建权威并保留回滚。
- **验收门槛**：官方 Miami 用户行为无回归；沙漠实例修改不影响 Miami；迁移可重复、可回退；失败时继续使用旧数据。
- **不做**：不移动现有 `apps/agent-city/ui` 来声称迁移完成；不把官方身份继承给外部内容包。

## C. 沙海之门视觉资产

设计：[EGYPT_DESERT_CITY_SPEC_2026_11_14.md](EGYPT_DESERT_CITY_SPEC_2026_11_14.md)。当前截图仍是 `arid-dunes-v1` + `desert` 基底，无巨门/砂岩/沙脊/沙尘/光照资产。

- **目标**：原创电影感沙漠城市资产：纪念性巨门、砂岩几何建筑、沙脊/沙丘、暖砂暮光与薄沙雾；可读道路、检查点与界面在同一光照下验收。
- **交付顺序**：
  1. 资产清单与版权/来源记录（`design/`）。
  2. 受限静态 GLB 制作与检查（尺寸/包围盒/材质/无外部 URI）；巨门优先。
  3. 运行时注册与资产引用；先只读展示，再进入项目/发布/试玩。
  4. 桌面截图 + 可读性审查；空城/测试 fixture 截图不计完成。
- **验收门槛**：桌面实际加载同一 City revision 的资产；巨门/建筑/道路/检查点在目标光照下可见；无越界/穿插/材质丢失；FPS/内存预算有记录。
- **不做**：不用程序生成的临时几何冒充原创资产；不在 world 包中携带应用代码或用户数据。
