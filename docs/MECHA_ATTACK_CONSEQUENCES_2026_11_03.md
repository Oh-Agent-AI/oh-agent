# PvE 目标试算与推挤反馈（2026-11-03）

## 范围

在既有本地 PvE 部署、规划和整回合预测上，补强目标选择时的后果表达。规则数据来自权威 `previewPlan` 的模拟结果，而非 UI 依据技能标称伤害自行推算；本轮不改变战斗规则、网络权限或远程协议。

## 实现

- 将目标试算分为「本次行动」和「整回合预测」：显示直接 HP 变化、实际修理量、行动结束后及回合结束后的目标 HP；预测阶段缺失时显示未知。
- 依据行动对应的模拟事件显示推挤起点、落点或受阻原位、碰撞对象及 HP 变化；当前行动直接击毁与推挤碰撞击毁分别标记，后续行动造成的击毁不归因于当前行动。
- 成功推挤用浅黄色箭头和落点框；Boss 使用完整 2×2 占格。受阻在原位显示红叉，不展示虚假落点。仅当模拟起点与可见目标位置一致时绘制棋盘推挤结果，避免错位造成误读；文字结果仍可查看。
- 上下文图例按实际成功或受阻解释标记。手机窄屏选定目标后，目标试算接管底部命令区域，确认/取消后恢复；鼠标悬停不会隐藏行动按钮，桌面悬停试算保留。长内容可滚动，焦点控件不会因面板高度拟合被裁切。

## 证据与限制

- 截图和逐场景结果：`artifacts/mecha-clarity-p0/consequences/mobile/`、`browser/`、`hud/`、`board/`、`tactical/`。`failure-*` 是修复过程的诊断截图，不是最终通过截图。
