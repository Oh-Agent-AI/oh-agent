# 原始 Agent City → 官方插件

目标：恢复原 City 的场景与交互，但运行在 Overview 平级 City Tab 的独立 Webview；浏览器使用相同 SDK 的 iframe 适配器。不恢复独立 AgentCity.app，也不引入宿主前端组件依赖。

## 功能对应

| 原功能 | 插件实现 |
| --- | --- |
| 岛屿、城区、建筑、道路、天空、天气、植被、动态设施 | 原渲染引擎与资源已迁入插件项目；场景仍由版本化投影生成。 |
| 时间范围、画质、标签、重置、航拍 | 由插件定义工具栏，宿主统一渲染和派发命令。 |
| 城区图例、城区聚焦、建筑悬停/选中 | 插件自己的浮层与详情面板。 |
| 时间轴、播放/暂停、速度、回到实时 | 原引擎回放 API，新增插件内时间轴。 |
| 岛屿种子、重建、短片/完整航拍设置 | 插件内设置对话框；受限 Rust 私有设置持久化，兼容旧种子。 |
| 建筑详情、用户输入上下文 | 展示投影统计及最多两条清理/截断摘录，不伪装为完整提示词。 |
| 完整 SessionDetail | 请求宿主导航到 Sessions；不把宿主组件或完整轨迹搬入插件。 |
| 航拍字卡、信箱遮幅、进度、退出 | 由插件叠层展示；字卡只用统计。 |
| PNG 拍照 | 原画布导出，浏览器下载；原生保存确认。 |
| MP4/H.264 视频导出/取消 | 独立 Worker + OffscreenCanvas；冻结统计模型与种子，不接管交互场景；后台节能画质，无 H.264 编码能力时明确不可用。 |
| 调试 FPS | 仅 cityDebug 开启时显示。 |

键盘可以通过设置中的会话选择器选中建筑；对话框支持 Escape 与可见焦点。普通 Tab 切换隐藏并暂停同一实例，保留相机、选择、设置及回放状态；返回恢复绘制。故障、显式重试或换另一个插件才销毁实例并清理资源。当前单插槽最多保留一个插件，不是多插件缓存池。导出在离开 Tab 时取消。

插件语言跟随宿主解析后的 `en` / `zh-Hans`，通过共享 SDK 初始化及更新通知传入。City 文案目录由插件维护；工具栏、内容与可访问性标签即时更新，不重建实例。用户摘录保持原文。日期/数字展示采用插件语言；视频字卡在创建导出任务时使用当前语言。

## 导出任务与线程

2026-10-04：默认格式改为 MP4/H.264，封装在原 Worker 中执行，不经中间 WebM。依赖、限制及最新验收见 `CITY_MP4_EXPORT_2026-10-04.md`；下方历史 WebM 验证数字保留，不作为 MP4 测试证据。

工具栏命令是“接受任务”确认，不等待影片完成：`city.film` 启动 Promise 后立即返回，SDK 发布 command.result；进度/完成/错误/取消由插件页面状态表达。不能把整个影片 Promise 挂在宿主 pending 命令上，否则长任务会触发命令超时。

视频导出现在有自己的专用 Worker，场景构建、WebGL 提交、字幕画布、VideoFrame 创建、编码和 WebM 拼装都在该 Worker 执行。交互画布不会 transfer，也不暂停实时引擎。UI 只负责克隆统计模型/种子、启动、显示进度、取消及最终 blob 下载；摘录不进入任务。引擎 headless 模式不创建 OrbitControls、DOM 监听和实时 rAF，纹理使用 OffscreenCanvas / ImageBitmapLoader。

采用 A 方案：Worker 从已经合成字幕的实际影片帧缩小生成预览，最多 640×360 / 2 FPS，通过可转移 ImageBitmap 展示在插件内。一次只允许一个位图在途；前台绘制并释放后确认，取消后迟到的位图也释放。预览不会推进另一套 3D 镜头，也不会改变影片的 30 FPS 时间戳；生成速度慢于实时属于正常离线导出。关闭设置不取消任务，Escape 优先关闭当前对话框；没有对话框时才取消导出。

自动画质从节能档启动，首分钟不升级，之后沿用连续高帧率窗口和迟滞策略；用户仍可显式选择高画质。避免首次加载就编译重型后处理，阻塞插件健康消息。宿主取消按钮同步显示导出百分比，作为独立于插件 WebView 无障碍缓存的状态入口；关闭对话框后 WebKit 仍可能漏报插件内预览节点，不能把这一平台现象声明为已修复。

工具栏首次发布就是既有宿主 ready 握手，因此 City 等待数据加载和模型首帧绘制再发布；空场景首帧不算就绪。数据不可用、空数据或 WebGL 不支持时走明确降级 UI 并完成握手。保留 15 秒启动超时、5 秒运行期健康/命令超时，不通过延长 watchdog 掩盖初始化阻塞。

检测到软件 WebGL 时，交互场景的实际绘制尺寸最多 640×360、最多 15 FPS，PNG 也限制为实际 640×360 范围并保持比例，不伪装成高清输出；硬件 PNG 保持默认 2560×1440。软件测试环境同时承受 UI 与后台渲染时，必须限制实际像素量，不能只依靠异步按钮或放宽测试超时。

视频生成期间禁止拍照，避免两个导出路径叠加原生保存窗口。选择目标后再次核验插件实例；macOS 保留非 sheet 保存对话框路径，rfd 0.15 同步 parent 路径会同时开启 sheet 与 runModal，实测出现保存按钮禁用，不能作为焦点修复。这属于并发/窗口生命周期加固，不代表此前窗口读取超时的根因已经确认。城区统计修正为独立第二列，预览不覆盖城区图例；查看建筑时让出对应信息区。

独立线程仍共享 GPU，不等于硬件资源隔离：后台使用节能场景，并按上一帧耗时安排约四倍的等待（80–5000ms），避免连续占满 GPU 队列；软件渲染检测为真时实际输出降至 640×360，并在进度中明确显示，不把它冒充 1080p。硬件路径保持 1920×1080 / 30fps。不保证任意设备零掉帧。

启动握手限 15 秒、无消息限 30 秒、总任务限 30 分钟；超时、取消、失败、完成都 terminate Worker 并清理计时器。编码数据上限为 256 MiB，达到上限明确失败，不静默丢帧。WebM 拼装去除了两个全文件临时副本，字节回归验证输出不变。离开 City 取消任务，不在其他 Tab 保留它。

缺少 Worker / OffscreenCanvas / WebCodecs 时按钮禁用；Worker 内 WebGL 或 VP8/VP9 不支持时提示不可用，不回退 UI 线程。PNG 拍照仍使用原交互引擎路径，本次后台任务改造针对视频。

背景：[Three.js 官方 OffscreenCanvas 说明](https://threejs.org/manual/pages/offscreencanvas.html)、[ImageBitmapLoader](https://threejs.org/docs/pages/ImageBitmapLoader.html)。浏览器同源 iframe 不保证独立线程/进程；本方案的计算线程边界来自专用 Worker，仍须单独验收原生平台。

## 数据差异（不要误报为全部数据已接通）

真实投影最多返回 500 个会话，窗口内 token 与事件数来自 authority DB。覆盖字段显示截断，不具备原旧分页加载器的全量加载能力。Findings 是部分 issue_instances 汇总，费用与模型详情尚未进入 City 投影；完整详情走宿主导航。

浏览器仍只接受合成数据，不能据此宣称原生进程隔离、保存对话框或真实数据显示已经验收。安装到 `/Applications` 的旧 APP 不会因源码更改自动更新。

## 回归入口

- `npm --prefix apps/desktop/ui-dev run verify:city`：布局/地形/航拍及架构边界。
- `npm --prefix apps/desktop/ui-dev run verify:city-runtime`：浏览器真实操作、种子、选中/摘录、拍照、导出取消，以及尺寸/画质/上下文恢复回归。
- `node scripts/verify-city-film-jobs.mjs`：真实任务客户端的握手、进度、终止、取消、超时、异常及缺失能力回归；WebM 低拷贝拼装的逐字节兼容回归。
- `node scripts/verify-react-city-runtime.mjs --film-only`：测试入口使用生产打包 Worker，在 320×180 / 1fps 下生成完整短片并解码，期间真实点击 UI 按钮并检查 UI rAF/计时器持续运行；不是 1080p 原生影片验收，不向生产插件添加测试 API。
- `cargo test -p agent-vitals-query --test app_local --release`：本地投影和 opaque handle 解析。
- 桌面 `cargo test --lib --release plugin_`：实例权限、设置、请求边界。
- 原生仍需 bundle 构建与实际 UI 验收，禁止裸运行 menubar 二进制。
