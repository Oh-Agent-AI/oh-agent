# A5：普通路面精确贴地与折叠修复

日期：2026-10-15。修复 [A4区域记录](CITY_SURFACE_REGIONS_NOTES.md) 中定位到的两类编译器缺陷。这是**有意的渲染几何变更**：平地夹具与重构前逐字节一致，坡地和闭合环线的输出变化记录在新基线中。

## 缺陷与根因

| 现象（修复前，十五城规划布局） | 根因 |
| --- | --- |
| 路段带最低处比「地形+0.04抬升」低0.29，埋进地形约0.25；路口扇面与路段带叠置高差最大0.30；驾驶区域判0–10对height-conflict，关闭路口 | 「这一截是平的」只在中点检查。渲染地形是extent/192网格上的分段线性面，中点恰好落在线性插值上时，四分之一处仍可偏离0.3 |
| 每城1–7个片段边界non-manifold/intersection（多为5宽、50°–90°折点）；驾驶层整段判closed | ① 斜接行的内侧顶点沿路向前伸出 `half·miter·sin(θ/2)`，沿线细分恰好在这段里插一行时，内侧四边形翻面叠在一起；② 1.4长的短桩比内侧伸出量还短；③ 闭合环线首尾两端都垂直截断，在角上交叠 |

先尝试过「按容差逐级加密」：陡坡上顶点涨到25万个仍然贴不住，所以放弃。

## 做法（`engine/surface/terrainClip.ts` + `groundRoadCompiler.ts`）

1. **精确贴地判定**：分段线性偏差的极值只出现在三类点上——边与地形网格线（x、z两组，以及每格对角线gx+gz=整数）的交点、三角形内部的地形顶点。全部检查一遍即为精确最大偏差，不是抽样。
2. **带子每个路点一行，不再沿线插行**。相邻两行组成一个条带，条带的两个三角形都贴地（≤ `ROAD_SURFACE_LIFT/2` = 0.02）就照旧输出，平地字节因此不变；否则按地形三角网把三角形裁成凸片，每片落在单个地形三角形里，偏差为0。扇面的扇区同理。
3. **不产生裂缝**：凸片顶点只能是三类规范点——角点、`edgeCrossings` 求出的边交点（端点按字典序规范化，正反两向结果逐位相同）、内部地形顶点。Sutherland–Hodgman 的输出吸附到这些点上；与已裁剪片段相邻的未裁剪三角形，在共享边上插入同一组交点，然后从质心扇形三角化。顶点按Float32量化后的坐标合并，避免上传后出现零面积三角形。
4. **折点与环线**：
   - 斜接内侧伸出量超过相邻段长的0.9时，才收窄斜接系数；
   - 收窄后条带变成凹四边形时，改用过凹角的对角线；
   - 闭合环线的首尾按折点各斜接一次，并共用同一行，网格焊成一个带孔的环。
5. 每个片段新增 `terrainDeviation` 字段（精确最大贴地偏差）。`unresolved` 列表改为 `validated-portals / channelized-islands / bridge-and-expressway-decks / cul-de-sac-surfaces`：同层合并和路缘语义已由 surfaceRegions 承担。

## 证据

- **基线**：`fixtures/city-driving/ground-surface-baseline.json` 原有的 `fixtures` / `generatedPlans` 是重构前（744f926a）的渲染缓冲，原样保留作存档。empty、straight、bend、tee、skew、width-transition、bridge-boundary 七个夹具仍与它逐字节一致。新增 `corrected` 段，只放 closed-loop、wavy-tee 和十五城，附原因说明；守卫断言改动的夹具恰好只有这两个。
- **贴地**：守卫用独立于编译器的稠密重心采样，逐个Float32三角形对照渲染地形。十五城最大偏差0.013–0.019，全部 ≤0.02（修复前最大0.33）。
- **拓扑**：十五城所有车行片段的边界都是流形。人行道仅seed 7 tier 3 有1个转角扇面例外：扇心是路口节点，圆弧不绕扇心单调，扇区互相重叠，修改前就存在，只影响人行道（不提供支撑）。守卫限定每城最多1个。
- **区分度**：两个新夹具在旧编译器上都失败，新编译器上都通过——锯齿地形（中点检查漏判：旧偏差0.160，新为0），以及1.4短桩接64°折点（旧为non-manifold）。
- **顶点数**：十五城共12.5k–45k个，与修复前（11k–44k）基本持平（+3%左右）；`verify-react-city-road-paint` 的城市网格上限、贴地、朝上、无孔检查全部通过。
- **下游**：
  - `verify-city-surface-regions --cities`：十五城高差冲突0、排除片段0，alias最大高差0.020（修复前0.100），每城区域1–3个（修复前最多9个）。
  - `verify-city-surface-store --cities`：未解决片段边界每城0个（7/3为上述1个人行道）。
  - `verify-city-driving-surface --cities`：600/600次开出≥12（修复前595/600）。
