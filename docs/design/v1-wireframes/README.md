# Agent Vitals v1.0.0 线框原型索引

> 版本：R2；日期：2026-09-10。低保真原型用于产品、设计与研发评审，不代表视觉终稿或功能已经实现。

## 体验主线

```text
首次打开
  → 零输入自动解析
  → 首份用量与名义成本
  → 浏览日历 / 小时 / 会话
  → 在结果上下文中确认计费方式
  → 预览并重算
  → 菜单栏持续观察 / 待处理恢复
  → 按需设置预算、账单、价格与隐私
```

## 一致性核对

| 核对维度 | PRD要求 | 原型表现 | 结论 |
|---|---|---|---|
| 首次输入 | 首份结果前必填为0 | 打开即扫描、解析，套餐与预算均后置 | 一致 |
| L0价值 | 先给真实用量和名义成本 | 首份结果同时展示用量、名义成本、价格覆盖 | 一致 |
| unknown兜底 | provider/付费方式未知仍按原厂价估算，保留不确定 | 总览、待处理、会话和确认面板均保留估算与待确认 | 一致 |
| 覆盖口径 | 采集、路由、价格、账单覆盖分别报告 | 主卡已明确为“价格覆盖”；来源和路由使用独立状态 | 一致；已修正文案 |
| 金额口径 | 名义、按量估算、订阅合同、已确认支出不可混用 | 页面分别命名；已确认支出与名义成本分层 | 一致 |
| 多币种 | 原币分列，不静默折算或直接合计 | 已确认支出展示为CNY、USD分列 | 一致；已修正文案 |
| 用户声明 | 有作用范围、预览、重算、回执、撤销；不抹掉事实 | 确认面板和回执场景完整覆盖 | 一致 |
| 数据源状态 | 无记录、未安装、权限不足、部分失败、正常分开 | 首次状态页和数据源页分别呈现 | 一致 |
| 失败恢复 | 局部失败不阻塞；旧结果继续可用；无半新半旧 | 部分失败、重新授权、重算失败均有恢复动作 | 一致 |
| 渐进配置 | 预算、账单、价格、隐私在价值出现后按需进入 | 单独可选配置页面；未设置不显示假0 | 一致 |
| 导航与下钻 | 总览→日→小时→会话，返回保留状态 | 日历、小时、列表、详情组成连续路径 | 一致 |
| 安静留存 | 菜单栏最多一项高价值提醒，无事项不打扰 | 菜单摘要和事项入口符合限制 | 一致 |

审查后未发现阻断性产品逻辑冲突。两处初稿歧义已修正：将“数据覆盖94%”改为“价格覆盖94%”；将不同币种的已确认支出从加号表达改为原币分列。

当前线框没有展开安全事件详情、每周回顾、关于与诊断、CSV错误行编辑等二级页面；这些能力仍由PRD约束，进入高保真设计时补画，不影响当前主链路一致性结论。

## 统一交互规则

- 每个页面只有一个主要动作；“待确认”用中性琥珀，“真实故障”才使用红色。
- 任何缺失状态都不能用0冒充；无记录、未计价、未设置、读取失败分别呈现。
- 复杂配置渐进披露；保存前预览影响，保存后给回执和撤销。
- 点击目标不依赖悬停；实现时提供完整键盘操作、可见焦点和图表表格替代。
- 最小窗口1024×700和200%字号下，主要动作、关闭/返回及错误恢复不得被遮挡。
