# v1.0.0 Phase C：持续使用闭环

## 目标

把“看见结果”变为可持续的日常价值：用户能找到高消耗工作、理解金额与证据、确认计费范围、观察重算结果，并在需要时设置预算和安静提醒。

## 范围

- 渐进计费与预算偏好：REQ-017–039。
- 菜单栏、总览、用量/会话、待处理、配置重算：REQ-048–088。
- 持续观察与交互/无障碍体验：REQ-109–123。

## 关键子闭环

### 计费确认与版本化重算

“确认计费方式”按执行环境、推测 provider/model、路由证据和时间范围聚合未确认用量。用户一次仅确认一条关系，可选最窄作用范围；保存前预览，保存后回执、撤销，并以同一声明/重算链路刷新所有视图。拥有订阅不自动覆盖第三方路由或所有历史。

### 预算与提醒

提供按量估算观察预算和已确认按量支出预算，独立币种和口径；默认未设置。阈值只在首次跨越时通知，可稍后或本周期静默；未计价使用存在时不能展示确定性绿色安全结论。

### 探索与待处理

总览、日历、小时、会话和详情保留统一筛选、时区与口径。会话先展示任务上下文和可解释异常，技术证据按需展开。待处理按问题族和证据归并；自动动作仅限本 App 配置、重扫和重估，绝不改执行环境文件或执行 shell。

### 安静观察

菜单栏显示数据新鲜度、当前重点和同步阶段；无变化不抢焦点。异常提示需有可比基线与覆盖，历史不足时不制造异常结论；通知默认不泄露任务标题、路径或金额。

## 验收锚点

- AC05、AC09–AC14、AC17–AC19、AC21–AC22、AC25–AC28。
- 重点复验：未知路线不归零；CNY/USD 不混算；修改历史声明可预览/撤销；重算失败仍读旧结果；一套筛选下所有消费面一致。

## 退出条件

用户可从总览定位一组未确认用量，选择计费方式和最窄范围，看到影响预览与重算回执，并从日历/会话/MCP 得到同一版本结果。预算、提醒与待处理均保留证据、范围和恢复入口，不作“已省钱”或“不会继续使用”的虚假承诺。
