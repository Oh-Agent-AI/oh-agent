# v1.0.0 Phase D：交付候选

## 目标

将功能稳定的 App 变成普通 macOS 用户可安装、可恢复、可理解并可获得支持的发布候选。

## 范围

- 本地数据控制与导出：REQ-124–128。
- 性能、可靠性与恢复：REQ-129–134。
- 安装、迁移、更新、帮助与诊断：REQ-135–142。

## 工作包

1. 隐私：默认本地分析；价格更新、统计和任何外部分析各自授权；不收集 API Key；导出预览、脱敏诊断、保留期与删除边界明确。
2. 性能与恢复：建立 10 万会话/100 万 facts 及 1GB 日志基准；测量启动、查询、资源和冷/热缓存；单实例、可取消、崩溃恢复及不可读数据库恢复页。
3. 安装与升级：Developer ID 签名、公证、最低 macOS/架构矩阵、应用内依赖、不依赖 shell/Python/开发目录；升级前备份并可恢复。
4. 用户支持：两分钟上手、术语、常见故障、升级/卸载说明、可选择提交的脱敏诊断包和可信下载入口。

## 验收锚点

- AC20、AC22–AC24，以及 AC01 的干净安装隔离复验。
- RELEASE-02、RELEASE-03 的技术前置。
- Apple Silicon/Intel 只对真实测试过的组合声明支持；签名、公证和无开发环境安装必须在真实环境验证。

## 退出条件

RC 可在无开发工具的干净 macOS 机器安装、启动、同步、退出重开并升级；性能结果可复现且记录偏差处置；磁盘满、权限撤回、数据库损坏和旧库迁移都有不丢数据的恢复路径。签名公证、帮助和诊断包均完成真实验收。
