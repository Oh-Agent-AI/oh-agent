# v1.0.0 Phase B：可独立上手

## 目标

让新用户或升级用户无需终端、注册、套餐或预算输入，即可在 macOS 上得到可解释的 L0 首份结果；没有日志或权限受阻时也明确下一步。

## 范围

- 自动启动、发现与导入：REQ-005–016。
- L0 名义成本总览、恢复和升级进入：REQ-040–047。
- 依赖 Phase A 的来源状态、统一查询、名义成本和版本化结果；不在本阶段自行计算金额。

## 体验合同

1. 打开 App 即在后台扫描 Codex、Claude Code、DSH 标准目录；有可读日志即优先导入近30天。
2. 首份结果前不要求账号、邮箱、API Key、套餐、预算或统计偏好；仅权限被系统阻止时请求对应授权。
3. 任一执行环境可用即可生成结果。未安装不报警；来源状态区分未发现、权限不足、无记录、导入中、部分失败、正常和暂停。
4. L0 必须展示真实会话/用量、名义成本、可估价覆盖、来源与最多三项可选完善事项；已确认支出未配置时不能为 ¥0。
5. 无日志提供选择位置与隔离的演示样例；样例不得影响真实库、通知、预算、导出或账单。
6. 中断后继续导入且不重复记账/索权；升级用户不重走向导。

## 实施分包

- 启动状态机与加载态：读取范围说明、暂停/进入设置、真实阶段与文件数，不显示假百分比。
- 执行环境发现与权限恢复：标准目录自动启用；自定义目录、暂停、排除、删除已导入数据在设置实现。
- L0 工作台：时间窗、来源、用量、名义成本、覆盖和非阻塞的套餐入口。
- 无数据、部分失败、恢复与升级路径：不把读取失败称作“暂无使用”。

## 验收锚点

- AC01–AC04、AC06、AC15、AC23、AC25。
- 仅 Codex、仅 Claude、仅 DSH 三种真实或受控 fixture 环境都能独立完成首次价值路径。
- 近30天优先导入、历史后台继续；AC/性能正式数值在 D 阶段用基准机复验。

## 退出条件

在干净机/干净 profile、单执行环境、无日志和权限撤回场景中，用户均可无需终端完成首份 L0 结果或获得可执行恢复操作。所有金额仍来自 A 的公共 DTO，未实现的套餐与预算绝不阻塞结果。
