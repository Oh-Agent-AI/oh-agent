# Mecha P1 本地 PvE 首版验收记录（2026-11-03）

## 范围与结果

本次交付本地 PvE 的救援任务、敌人行为区分、击退后果说明和固定局面难度回归测试，**不是《MECHA_GAMEPLAY_UPGRADE_PLAN_2026_11_02.md》中全部 P1 的完成证明**。

- 救援任务：战场设置中可选择本地救援。部署时校验救援点在初始静态局面有路可达；整个行动计划合法且整队移动结束后，只要存活机甲抵达目标即胜利，不再执行后续攻击。全灭或 15 回合耗尽失败；敌人全灭及建筑全毁不单独决定救援任务胜负。目标以紫色十字标记，目标面板提供文字和坐标。
- 敌人：救援模式按 ID 确定性区分攻城和拦截偏好，选中敌人时提供中英文行为说明。仍使用现有攻击技能和提前宣告的落点；攻城单位在建筑全毁不算失败的任务中施压有限。原有模式不更改其行为。
- 击退预览：根据规则事件展示方向、落点及碰撞结果。规则聚合为 wall 的情况只提示地形、障碍或边界，不能断言具体类型；无效预览不会继续显示旧结果。
- 难度：增加固定局面的 easy/normal/hard 配置和合成 AI 回归测试，未依据合成结果调整数值，也不将其等同于玩家胜率或平衡验证。
- 本地救援回放使用 `mecha-local-replay:v2`；旧模式仍使用 v1。救援为本地限定，远程入口显式拒绝该模式；尚未发布的早期实验性 v2 记录不保证跨迭代兼容。
