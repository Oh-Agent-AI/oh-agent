# City 数据设施与建筑详情呈现方案

版本：1.0 · 日期：2026-10-20 · 状态：首批呈现实现；真实 App 验收待完成

## 1. 决定

City 的统计需要明确的空间入口，同时保留不依赖地图规模的“数据设施”目录。已有公共建筑足以承接第一批数据，不新增只有外观或空面板的建筑。设施的实体位置来自现有规划；数据入口不能因为城小、学校/医院未生成而消失。

公共设施是数据服务入口，不代表真实使用次数、任务成功或游戏收入。会话仍然是一栋楼；公共设施不是另一个会话，不增加会话总量。游戏等级、金币和经营面板保持独立。

## 2. 空间与信息映射

| 设施入口 | 复用的实体/模型 | 信息范围 | 首批状态 |
| --- | --- | --- | --- |
| 市政厅 · 城市总览 | civic-hall / decor:site:civic | 全窗口会话、usage 事件、token 分桶、载入覆盖；窗口统计与几何子集分开 | 展示真实投影 |
| 城市观测站 · 活动与模型 | observation-tower / decor:site:tower | 每日活跃会话、usage 行和 token；最忙日及排序依据；完整窗口模型 ID 与未知覆盖 | 展示真实投影 |
| 诊断中心 · Findings | hospital / decor:civic:hospital | 当前 open/later 积压与窗口新增分别列出；severity/category/harness | 按需读取已授权聚合；能力缺失有说明 |
| 技能学院 · Skills | school / decor:civic:school | 未来：有调用证据的使用次数、最近活动与结果覆盖 | 当前投影未注册，明确 unsupported；安装数量不能代替使用次数 |
| 调度站 · Workflow | station / decor:site:station | 未来：已配对调用、结果与时长覆盖 | 当前投影未注册，明确 unsupported；不把 usage 行数当调用数 |
| 会话楼 · 单次活动 | 原有 session 楼 | 标题与来源、安全楼号、窗口/生命周期、四类 token、模型、分项估价、有限摘录 | 初始轻量信息；详情按需加载 |
| 城区地标 | 原有 district landmark | 该执行环境已载入会话、今日活跃、覆盖说明；提供全城设施目录入口 | 保留城区介绍，不复制全城数据冒充城区统计 |

## 3. 用户路径

1. 点击地图公共建筑：先看到它的建筑介绍和对应数据入口，例如医院介绍中的“打开诊断中心”。
2. 点击“打开数据”：在同一右侧区域打开非模态数据面板，地图仍可旋转。关闭/返回恢复建筑介绍，Esc 只关闭当前数据面板。
3. 不知道设施位置或设施尚未生成：从城市摘要的“数据设施”目录直接打开。面板可尝试“定位建筑”；不存在时说明“当前规模尚未生成该设施”，不虚构位置。
4. 会话楼详情显示安全楼号、有限摘录的 session scope、费用缺失原因和按币种/依据的分项。原始路径和原生 session id 仍由宿主本地详情负责。

## 4. 信息层级

首屏为设施名、数据用途、窗口/时区/生成时间与来源。其次是 3–6 个主要数值；最后为模型、每日活动或问题分类列表。每天的三项活动分别标注，绝不都写成“调用数”。

费用仅在有可靠来源的位置显示。没有全窗口成本汇总时，不把已载入楼宇估价相加伪装成全城成本。首批不新建金融中心；后续具备完整窗口、多币种、部分计价与订阅覆盖后再评估“账务中心”。费用不映射租金或建筑价值。

## 5. 加载与状态

- 进入面板即有明确读取状态，取消/关闭后不交付陈旧结果。
- ready、empty、unsupported、unavailable、stale 分别说明；unsupported 不显示“0 次使用”。
- v2 窗口为闭区间、UTC 日桶；v3 为半开区间和明确的 IANA 时区。面板读取独立新快照时显示它自己的窗口与生成时间，不合并进旧几何统计。
- 模块失败不清空城市。用户可以明确重试读取；不以合成数据掩盖真实查询错误。
- 初始场景使用兼容路径；v3 分页测试开关需完成全城渐进布局和原生性能验收后再成为默认入口。

## 6. 是否新增模型

第一批不需要。当前已有市政厅、医院、学校、车站、观景塔及城区地标。通过设施标题、建筑介绍和“数据设施”目录，让它们有明确用途即可。

后续只有同时具备独立数据内容、实际交互价值和稳定选址预算时才新增模型：账务中心（完整成本模块）、技能工坊（技能实际使用与诊断）、自动化控制中心（有覆盖保证的 workflow）。不能为未接入数据先造“零统计”设施；新增几何须重新验证道路、步行/驾驶净空、碰撞代理和拾取。

## 7. 验收

- 市政厅/观测站/医院点击后能看到对应数据，目录入口在小城也可用。
- 全窗口总量不受 4000 栋渲染上限影响；已载入和全窗口文字明确。
- 医院的旧问题仍在当前积压；窗口内已关闭问题仍在窗口新增。
- Skills/Workflow 未注册时显示能力说明，不显示虚构次数。
- 关闭面板或切换设施取消结果交付；请求失败保留城市。
- 中文和英文、键盘焦点、Esc 返回、窄屏滚动、44px 交互目标、宿主撤权均验证。

本文只定义数据呈现，不承诺自动关闭 Findings、启动技能、修复真实问题或发放游戏奖励。


## 8. 城区配套实施修订

全城保留唯一市政大厅及中央观测站；每个非空 Harness 城区在会话落楼前优先申请医院与学校。设施使用 `civic:<districtId>:<kind>` 稳定身份，在本区锚点附近的合法街区选址。可选商场等随后随本区规模增长。已建的合法新身份设施在刷新时保留；旧数字编号设施在本次布局升级时重新规划。

城区地标与摘要目录提供本区诊断/学院入口；医院、学校拾取后从真实布局解析 districtId。诊断模块在 Rust 服务端验证 Harness 身份并过滤问题与能力，面板标注所属执行环境。全城目录仍提供跨区视图。技能和 Workflow 仍 unsupported，不以零使用替代。

本区医院可定位到具体城区实例；区级调度站尚未新增实体。没有合法完整街区或预算耗尽时，规划报告保留失败，地标明确显示缺建设施，服务目录仍可用；目前不自动扩大岛屿，也不牺牲道路净空强行生成。因此这是每区优先规划及覆盖检查，不承诺所有种子和任意数量 Harness 均已实现实体覆盖。

新增回归覆盖 12/280/700 会话各城区医院与学校独立用地、后端 Harness 隔离与非法 Harness 拒绝。浏览器合成演示验证 Codex 专属诊断和医院定位；原生 bundle 待验收。

## 9. 学校 Skills 数据接入

学校现在使用 `city:v3/module.read` 的 `skills` 模块，沿用已授权 City 实例与快照校验，支持可选 Harness 过滤。数据库共享查询读取既有 workflow_events 并通过 sessions 关联 Harness；不扫描安装目录或读取原始日志，不改变 MCP/export。

允许字段：Harness、经清洗且有界的技能标识、窗口内 skill_invoked 数、涉及会话数、最近调用毫秒时间、skill_finished 总数及 succeeded/failed 数。每次最多 200 个技能与 Harness 组合并显式标记截断。窗口半开；无 session 归属的事件不能分配给城区，因此排除。返回 observed_workflow_events_only 覆盖说明，不声称源数据完整；无记录为 empty，不能推断零使用。

结束事件并未与调用逐一配对，且可能来自窗口外的调用，故不计算成功率或把“调用减结束”解释成执行中。技能标识清洗后呈现，不返回 session_key、原始路径、参数、错误或提示词；敏感标识显示 redacted。

浏览器 demo 使用明确标记的合成技能样例；真实安装仍需包含本轮 Rust 宿主重新构建。学校建筑介绍同步更新为城区服务规则。Workflow 仍未接入。

## 10. P1 工作流与建筑收藏（2026-10-20）

- Workflow 设施现在按窗口和执行环境查询 `workflow_events`，内联展示任务、工具、技能、模型切换和审批拒绝的已知事件类型汇总；只返回事件类型、计数、涉及会话、最近时间及失败事件数。最多 200 个执行环境/事件组合，截断显式标记。
- 开始和结束事件没有逐次配对，不推算成功率或当前运行任务。未锚定会话或缺少采集记录不是零使用。不会返回 capability 名、参数、错误文本或源路径。
- 建筑详情提供原生本地收藏，最多 200 个稳定 `asset_ref`。宿主处理器挂在状态键 `game-links:v1` 上，谁能调用只看描述符有没有声明这个键，不再额外要求插件 id 是 City。这份存档在宿主侧只有一份（`city-primary`）；档案版本与 resolve 引用授权在同一 SQLite 事务内提交。非法/未知引用、过期 revision、额外字段拒绝，失败不改变存档或授权。
- 收藏状态通过 `assets.resolve` 显示窗口内、窗口外、来源删除、来源缺失等覆盖信息；浏览器演示不伪造宿主引用授权。收藏不是经济系统，不产生货币或收益，不包含分析文本。
- 验证：City v3 集成测试覆盖工作流范围/窗口/脱敏及收藏冲突/未知引用/取消收藏授权撤回；桌面测试覆盖实例插件标识和 state key 白名单。
