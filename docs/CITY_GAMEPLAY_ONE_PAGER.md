# Agent City｜一页纸游戏策划案

**定位：把日常 Agent 会话变成资产，用租金建设城市、升级汽车和飞机的单机游戏。**

白天的工作留下 Session 建筑；空闲时收取租金、选择投资，再开车或驾驶飞机体验自己建设的城市。核心感受：**“这座城市来自我的积累，也按我的喜好成长。”**

## 核心循环

**Session 建筑产生租金 → 一键收取金币 → 升级市政、建设道路、升级载具、购买装修 → 体验新路线与新性能 → 选择下一个目标。**

面向希望在工作后放松、建设和探索的 Agent 用户，每次约 15–30 分钟。基础玩法全部采用确定规则，不依赖大模型生成剧情。

## 四类投资，一份预算

| 投资方向 | 玩家做什么 | 实际收获 |
| --- | --- | --- |
| 市政建设 | 升级市政厅、车库和机库 | 更多收益槽，开放汽车与飞机配件目录 |
| 道路工程 | 投资预设支路、捷径和经过验证的连接工程 | 新路可以亲自驶过，城市探索范围更丰富 |
| 载具升级 | 购买汽车动力/操控、飞机动力/操纵配件 | 更好的加速、爬升或响应，能实际试驾比较 |
| 商店装修 | 购买建筑配色和墙面喷绘 | 让酒店和街区体现个人风格 |

关键选择：**“先修一条新路，还是把自己的车升级？要不要先扩大经营容量，为下一项工程攒钱？”** 四类投资不强制固定顺序。

## 商店里的个性化

买一套“迈阿密落日”配色和一幅海浪喷绘，装饰自己的海滨酒店，再沿海岸驾车欣赏。商品永久解锁，兼容建筑可反复使用，免费恢复原色；购买前预览昼夜效果。首轮仅适配一种经过核验的酒店模型、固定墙面和预制图案，不做自由涂鸦或模型生成，不改变数据楼高、租金和碰撞。

## 收租与成长

租金自动累计、一键领取，离线最多累计 72 小时。首版市政厅提供 4 个收益槽，可升级到 6 个；历史会话多提供更多建筑选择，不无限增加产能。少数据用户用明确标识的公共物业补足，所有人都能玩完整循环。

原型启动资金 300 金币：可以选择 240 升级市政、160 建设首条道路，或 180 升级车库并购买一项汽车配件。数值待试玩调优。可选驾驶/飞行挑战补充收入，不要求等待或增加真实 token 消耗；已有基础载具与自由驾驶保持可用。

## 第一场体验

认出自己的会话楼 → 查看租金 → 比较四种投资 → 完成首次建设或升级 → 驶过新路、试用新配件，或增加收益建筑 → 留下下一项目标。退出后仍有受限租金积累，下次打开即可查看。

升级必须产生真实效果。程序缺陷免费修复，不能把桥头碰撞错误包装成收费修路；车辆升级不能穿墙。游戏金币不等于真实费用，游戏升级不改写 Session 统计。

## 首版范围与验收

交付收租与存档、市政厅/车库/机库 L1–L2、两个预设道路工程、汽车与飞机各两项配件、2–3 个可选人工挑战，以及酒店装修小样（三套配色含免费原色、两款喷绘）。暂不做角色剧情、抽卡、自由画路或完整社会模拟；模型对白仅作为未来可选增强，个人数据保持本地。

**验收重点：收租购买可靠，工程可以通行，配件升级可感知，装修能预览且保存正确；没有奖励也愿意驾驶，离开前知道下一笔钱想花在哪里。**
