## Top 5 优先补测排序

1. **CI：desktop crate `cargo test --lib` 进 verify.yml 必跑集**（§7 P1-7a）。理由：现有 20 个高质量回归测试（安装事务 9 项是 RFC §1.1-3 明言要平移给 Story 安装的模板）目前只在本地跑；且本审计实测并发中间态能让 desktop 编译红而不被任何 CI 发现。工作量 S（一条 workflow job）。
2. **code_preview_window 命令面守卫测试**（§2 P1-2a/2b，两个用例）。理由：`preview_instance_mismatch` 与三层 allowlist 是独立 Preview 窗口的隔离核心，零覆盖；这也是 RFC §13 收敛面里唯一完全没被测过的防线。工作量 S-M。
3. **creator_code_game 容量回收 + sealed build 负例矩阵**（§3 P1-3a/3b，两个用例）。理由：容量回收是用户日常可触发的 fail 路径；sealed 负例是"只读密封字节"不变量的完整证据（现在只有 1/8 个篡改轴被测）。工作量 M。
4. **city_runtime run TTL/active_slot 生命周期**（§4 P1-4a，一个用例）。理由：V3-09（重复 Intent、崩溃恢复、CAS）验收依赖 run 生命周期语义，当前 30min TTL 与 slot 唯一约束无自动化证据。工作量 S-M。
