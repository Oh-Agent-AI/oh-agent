    关于本工具

    • 复刻自 ip.net.coffee/claude 的能力，独立实现：所有检测由浏览器直接向下方公共接口发起，本页面没有任何自建后端，也没有任何数据上报。
    • 数据源：claude.ai 与 www.cloudflare.com 的 /cdn-cgi/trace、myip.ipip.net（国内视角）、ip-api.com（geo + proxy/hosting 标记，免费版仅 HTTP）、ipwho.is（回退 geo）、edns.ip-api.com（DNS 解析器出口）。
    • 与原站的差异：信任分不用黑盒评分服务，而是把扣分规则写明在本页（见信任分卡片）；Tor / 爬虫 / 滥用记录没有可靠免费源，如实标注「不支持」。
    • 部署提示：请通过 HTTP（如 python3 -m http.server 后访问 http://localhost:8787）打开。若部署到 HTTPS，ip-api（HTTP-only）一项会自动降级并提示。
